# 추천 글 댓글

Today의 각 발행 ID에 사람 댓글을 붙인다. 종목이 같더라도 AI·발행물이 다르면 댓글을 공유하지 않는다. 과거 발행 ID는 보존한다.

- 카드 아래 댓글을 펼쳐 닉네임(1~24자)과 본문(1~1,000자)을 입력한다. 닉네임은 계정 인증을 뜻하지 않는다.
- 본문은 서버에 저장하고 다른 브라우저에서도 읽는다. 브라우저에는 닉네임만 저장한다. 작성 중 본문과 재시도 ID는 메모리에서 유지한다.
- 같은 브라우저의 HttpOnly 익명 소유 쿠키로 본인 댓글을 삭제한다. 쿠키가 사라지거나 다른 기기로 이동하면 본인 확인이 이어지지 않는다.
- 추천 댓글은 AI에게 자동 전송하지 않는다. 기존 회원제 /api/community 서버와 독립적이다.

## 서버와 저장

/api/recommendation-comments: GET reportId/before, POST reportId/name/body/requestId, DELETE reportId/commentId. 공개 스냅샷의 검증된 발행 ID만 허용한다. GET은 최신 50개와 count/nextCursor를 반환한다.

Vercel 프로젝트에 연결한 private Blob 저장소를 사용한다. BLOB_READ_WRITE_TOKEN은 서버 전용이며 정적 빌드에 넣지 않는다. 발행별 JSON을 ETag 조건부 쓰기로 갱신하고 충돌 시 최신 내용을 읽어 재시도한다. 작성 재시도는 requestId로 중복을 막는다. 삭제 권한·요청 크기·빈도·같은 출처를 서버에서 검증한다. 서버 연결 실패 시 503을 반환하고 화면은 실패를 표시한다.

npm ci 후 npm test 및 npm run build로 검증한다. 개발 서버도 동일 API 경로를 지원한다. 로컬 실저장 확인에는 별도로 안전하게 전달한 서버 환경변수가 필요하며, 비밀값을 Git·정적 파일·로그에 넣지 않는다. 테스트는 주입한 메모리 저장소로 CAS 충돌·발행물 격리·권한·유효성·중복 요청을 검증한다.

## 운영 범위

추천 카드 댓글과 기존 회원제 종목 토론/AI 워커의 운영 상태는 구분한다. 추천 댓글 연결이 기존 커뮤니티 전체의 운영 완료를 뜻하지 않는다. Blob 사용량은 기존 Vercel 프로젝트에서 확인하며 무료 포함량을 영구 무제한으로 간주하지 않는다.
