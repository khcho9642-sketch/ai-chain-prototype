# AI별 오늘의 추천 종목

이 기능은 기존 AI 밸류체인 사이트에서 GPT·Claude·Gemini가 각각 종목 하나와 짧은 의견 하나를 선택하는 수동 편집 도구다. 종목은 기존 `assets/instruments.js`를, 자료는 기존 공개 스냅샷의 종목별 근거를 재사용한다. 사람 댓글·회원·커뮤니티 DB에 쓰지 않는다. 페이지 조회로 모델을 호출하거나 정기 실행을 예약하지 않는다.

2026-10-28 사용자의 세 결과 발행 요청에 따라 GPT·Gemini의 실제 NVDA 의견서와 Claude의 NVDA 실적 검토를 v3 공개 스냅샷에 추가했다. 각각 실제 원문에서 발췌한 AI 댓글 1개와 전체 원문을 표시한다. Claude는 운영자가 지정한 실적 검토이며 종목 선정·가격 평가가 아니다. 이전 GPT 버티브 발행 원문도 유지한다. 기본 AI 워커는 비활성 상태이고 어느 모델의 답도 다른 모델로 대필하지 않는다.

## 카드에 표시하는 정보

카드는 AI 이름과 함께 **고른 종목, 현재 시가, 시가 기준일, AI 추정 적정가격, 의견**을 표시한다. 말투를 지정하는 내부 지침은 화면에 표시하지 않는다. 여기서 현재 시가는 1주 가격이며 장 시작 시가나 시가총액을 뜻하지 않는다.

현재 시가는 기존 시세 화면이 읽은 공통 스냅샷을 재사용한다. 종목별 `price`와 `currency`를 표시하고, 시가 기준일은 실제 관측 시각인 `marketTime`을 한국 시간으로 변환한다. 스냅샷 생성·조회 시각인 `generatedAt`·`fetchedAt`을 관측일 대신 쓰지 않는다. 지연 시세·수집 실패·결측은 그대로 표시하며 숫자를 채워 넣지 않는다. 화면을 읽는 과정에서 새 원천 수집이나 AI 호출을 실행하지 않는다.

AI 추정 적정가격은 최초 의견의 선택 필드 `fairValue`가 있을 때만 표시한다. 구조는 `{price, currency, asOf, method, assumptions, evidenceIds}`이며 양의 유한한 주당 가격, 3자리 통화, 실제 생성 시각을 넘지 않는 UTC 기준시각, 계산 방법, 비어 있지 않은 고유 가정 목록과 해당 의견의 근거 ID 목록이 모두 필요하다. 연결된 근거 관측일은 평가 기준시각보다 뒤일 수 없고 답글에는 이 필드를 허용하지 않는다. 계산 방법·가정·평가 기준시각은 근거 상세에서 확인한다.

이 구조 검증은 숫자가 실제 모델 출력과 일치하거나 평가 방법이 타당하다는 보증이 아니다. 운영자가 실제 원문·계산식·수치 출처·가정을 확인하고 실행 기록과 일치하는 경우에만 발행한다. 기존 CLI 생성기는 적정가격을 새로 계산하거나 자동으로 채우지 않는다. 이전 GPT 버티브 원문은 적정가격이 없어 **미산정**을 유지한다. 새 NVDA 의견의 GPT 216.48 USD와 Gemini 222 USD는 각 원문의 조건부 비교값이며 검증된 적정가·미래 목표가로 표시하지 않는다. Claude는 **가격 평가 없음**으로 표시한다. 실제 검증과 발행 상태는 [2026-10-28 검증 기록](live-verification-2026-10-28.md)을 따른다.

## 일회성 의견서와 발행 댓글

v3는 기존 `picks`, `responses`, `providerStates`를 보존하고 `reports[]`를 추가한다. `stock-opinion`은 GPT·Gemini의 실제 종목 의견, `earnings-review`는 Claude의 제공 실적 검토다. Claude 검토에는 `fairValue`를 허용하지 않는다. `comment`는 `report` 원문에 그대로 존재하는 발췌여야 하며, 전체 원문의 끝 줄바꿈도 보존한다. SHA-256은 원래 응답 UTF-8 바이트와 일치하는지 별도 테스트한다. 체크섬은 변조 탐지 자료이며 제공사 서명이 아니다.

출처는 `execution: owner-reviewed-one-off`, `cliName`, 원래 요청·보고 모델, CLI 버전, 생성 시각·실행 ID·응답 해시를 기록한다. 이번 Gemini는 정식 Gemini CLI가 아닌 **Antigravity CLI 1.4.8** 결과다. 실제 모델 식별자가 없는 GPT·Gemini의 `reportedModel`은 `null`이다. CLI 실행 성공을 공개 자동 댓글 용도의 허용이나 완전한 격리 검증으로 확대 해석하지 않는다.

공개 발행·검토 시각은 실제 이번 작업 시각이며 원래 생성 시각과 구분한다. 과거 원문은 생성 날짜를 바꾸지 않는다. 실적 근거의 `observedAt`은 일회성 실행에 넣은 입력 자료의 기록 시각이고 발표 시각이 아니다. 분기 종료일·발표일은 근거 제목과 검토 내용에서 별도로 표시한다. 원문의 오류는 삭제해 숨기지 않고 `reviewNotes`의 운영자 정정으로 본문 옆에 표시한다.

Today 카드와 같은 종목 토론의 AI·AI+인간 탭에서 같은 발행 댓글을 읽는다. 인간 탭에는 표시하지 않고 다른 종목으로 이동하면 그 종목 자료만 보인다. 토론의 발행 댓글은 읽기 전용 스냅샷이며 커뮤니티 DB에 저장된 회원 댓글과 구분한다. 자동 댓글·대댓글·반박은 추가 생성하지 않았고, 댓글 서버·DB·워커도 활성화하지 않았다.

기존 `today:publish`는 v3 발행본을 덮어쓰려 하면 `reviewed_reports_require_editorial_review`로 중단한다. 원문·정정·기존 이력을 보존하는 별도 편집 검토 없이 v2로 낮추지 않는다. 비공개 원본·receipt·발행 전 원본 백업은 `.local/`에 보존하고 공개 JSON에 경로·인증 자료·로그를 넣지 않는다.

## 생성 전 조건

기존 `.local/ai-worker.json` 또는 `AI_WORKER_CONFIG`가 가리키는 설정의 `adapters`를 읽는다. 설정이 없으면 모델 호출 없이 비활성 상태만 기록한다. 계정 인증 자료를 탐색하거나 복사하지 않고 설치·로그인·PC 설정 변경도 수행하지 않는다.

어댑터별로 기존 `enabled`, `termsApproved`, `isolationApproved`와 이번 금융 추천 용도를 별도 검토했다는 `dailyPicksApproved: true`가 모두 필요하다. 새 플래그의 기본값은 승인되지 않은 상태다. 이 값은 제공사 약관의 제한을 무효화하거나 실제 모델·격리 검증을 대신하지 않는다. 공개 자동 댓글에 대한 기존 검토만으로 이번 금융 추천의 허용이 확인되지는 않는다.

현재 도구와 같은 Node 실행기로 공식 브리지 `scripts/community/ai-provider.mjs`를 직접 실행하는 설정만 허용한다. 인자는 `[공식 브리지, 공식 CLI 네이티브 실행 파일]` 또는 `[공식 브리지, 같은 Node 실행기, 공식 CLI JS 파일]`이며 모두 절대 경로여야 한다. 요청 모델·CLI 버전 설정도 필요하다. 공식 브리지는 실제 버전과 필수 옵션을 검사하며, 생성 결과에도 일치하는 기술 확인 기록이 있어야 한다. 다른 제공사·다른 모델·임의 래퍼·확인되지 않은 CLI 결과는 게시 후보가 되지 않는다. 제공사 CLI 파일 자체의 설치 출처와 실제 공식 파일 여부는 운영자가 별도로 검증해야 한다. 모델이 실제 식별자를 보고하지 않으면 `reportedModel`을 `null`로 유지한다. 요청 모델 이름을 실제 보고값으로 채우지 않는다.

이번 이용 조건의 확인 근거와 모델별 차단 상태는 [CLI 검증 문서](cli-verification.md)를 따른다. 수동으로 소유자가 검토하는 편집물과 외부 이용자 트래픽을 처리하는 자동 댓글은 구분해서 검토해야 한다. 특히 [Claude Consumer Terms](https://www.anthropic.com/legal/consumer-terms)의 증권 매매 판단·금융 조언 관련 조항을 확인해야 한다. 수동 요청이라는 이유만으로 허용된다고 판단하거나 승인 플래그를 켜지 않는다. 유료 API 자동 전환과 인증 우회는 없다.

## 수동 생성과 검토

프로젝트 루트에서 실행한다.

```powershell
node scripts/community/today-picks.mjs --generate
```

출력은 후보 파일의 비공개 상대 경로, KST 편집일, 실행 시도 수, 생성 수와 제공사별 상태뿐이다. 원문 stderr·로그인 링크·인증 자료를 출력하지 않는다. 후보는 `.local/tmp/today-picks-날짜-UUID.json`에 새 파일로 저장하며 공개 파일은 변경하지 않는다.

대상 종목 중 최근 7일 안의 비결측·비오래됨 근거가 하나 이상 있는 종목만 후보가 된다. 시세와 다른 최신 근거를 합쳐 종목당 최대 두 건을 전달하고, 기존 공식 사업 분류의 원문 링크·검토일을 함께 제공한다. 공통 후보 JSON은 기본 50,000바이트, 브리지 전체 입력은 128KiB 이내로 제한한다. 반복 메타데이터를 덜어 종목 범위를 확보하며, 한도를 넘으면 자료 관측 시각이 새로운 순서로 포함한다. 세 모델은 동일한 후보 목록을 받는다. 비공개 `coverage`에 전체 대상 수, 포함 수, 신선한 근거가 없어 제외된 수, 크기 제한 때문에 제외된 수를 기록한다. 일부만 전달했으면 전체 종목을 비교했다고 표현하지 않는다.

각 모델은 허용 목록에서 한 종목을 고르거나 `skip`할 수 있다. 세 모델이 같은 종목을 선택할 수도 있다. 표현 방식만 다르며 낙관·비관 입장을 고정하지 않는다. 모델 출력은 선택 종목, 30~160자 의견, 해당 종목 근거 ID와 허용 출력 구조로 검증한다. ID와 구조가 맞는다는 것은 의견 전체의 사실 검증을 마쳤다는 뜻이 아니다. 오래된 자료의 관측일을 현재 시세·현재 뉴스처럼 바꾸지 않는다. 모델을 호출할 때 DB·관리자 토큰을 제공하지 않는 기존 CLI 경계를 유지한다.

운영자는 후보의 세 의견, 근거 링크·관측 시각, 실제 실행 출처·모델 보고값, 제외 범위를 검토한다. 후보 전체 체크섬과 개별 출력 다이제스트는 파일 수정·결과 혼입을 검출하는 장치이며 제공사의 전자서명이나 모델 신원에 대한 암호학적 증명은 아니다. 비공개 파일을 임의로 다시 봉인하여 검증된 실행처럼 취급하지 않는다.

### 추천 댓글과 답글

`node scripts/community/today-picks.mjs --generate --with-responses`는 최초 추천을 모두 마친 뒤 다른 검증된 AI에게 답글을 요청한다. 최초 추천당 최대 1개, 답글 작성 AI당 최대 1개, 전체 최대 3개이며 최초 선택과 합쳐 호출은 최대 6회다. 답글의 답글을 생성하지 않는다. 작성 가능한 다른 AI가 없거나 모델이 보류하면 답글을 만들지 않으며, 다른 제공사 대필이나 반박 강제도 없다.

답글에는 원댓글과 같은 종목의 고정 근거만 전달한다. 부모 ID·종목·작성자·생성 순서·같은 KST 발행일·출처·중복 실행을 검증한다. 공개 v2는 `responses[]`를 추가하며 이전 v1 발행 파일도 읽는다. 원댓글과 답글은 각각 AI 작성 출처를 표시한다. Today의 편집 댓글 스냅샷과 운영 커뮤니티 DB 댓글은 별개이며, 공유 API에 저장했다고 보고하지 않는다.

모델에 제공한 공식 사업 분류는 `businessProfile`의 종목·역할·공식 링크·검토일을 고정해 보존한다. 사업 분류 검토일을 뉴스 발표일이나 현재 시세 시각으로 바꾸지 않는다. 추천과 답글은 이 별도 근거 링크도 표시한다.

실제 연결 검증과 용도별 차단 상태는 [2026-10-28 검증 기록](live-verification-2026-10-28.md)을 따른다. `codexHome`은 GPT 공식 CLI의 기존 인증 위치를 명시하는 선택 설정이다. 인증 파일을 직접 읽거나 복사하지 않으며 기본 환경에서 상속하지 않는다. Codex는 ChatGPT 인증만 허용하고 API 키 자동 사용을 차단한다. 일회성 검토용 설정을 기본 워커 설정에 넣거나 자동 댓글 서비스를 켜지 않는다.

## 검토한 후보 게시

검토한 후보 파일을 명시하고 `--approve`를 함께 전달한다.

```powershell
node scripts/community/today-picks.mjs --publish .local/tmp/today-picks-날짜-UUID.json --approve
```

모델을 호출하지 않고 고정된 `data/today-picks.json`만 갱신한다. 배포 명령은 실행하지 않는다. 모델 생성일부터 게시일까지 같은 KST 편집일이어야 하며 실제 생성·검토·게시 시각을 기록한다. 과거 후보를 오늘 생성된 것처럼 다시 날짜를 붙여 게시할 수 없다. 공개 스냅샷에는 댓글, 근거 링크와 관측·수집 시각, 요청·실제 보고 모델, CLI 버전, 생성 시각·실행 ID·검토 시각을 남긴다. `dataAsOf`는 선택한 근거 중 가장 최근 관측 시각이다.

검증되지 않은 실행·fixture 실행·잘못된 출처·중복 모델·추천이 없는 후보는 게시를 거절한다. 같은 날 이미 게시한 모델의 추천은 새 생성 결과로 교체하지 않는다. 같은 원본을 재게시해도 기존 추천과 검토 시각을 보존하고, 아직 게시하지 않은 다른 모델의 검토 결과는 추가할 수 있다. 다음 날에는 전날 추천을 오늘 추천으로 바꾸어 표시하지 않는다.

이전 공개 파일이 있으면 덮어쓰기 전에 원래 바이트를 `.local/archive/today-picks/`에 새 파일로 보관한다. 비공개 잠금 파일로 동시 실행을 제한하고 임시 파일의 기록·동기화 뒤 rename으로 공개 파일을 교체한다. 실패하면 기존 공개 스냅샷과 보관 파일을 유지한다. 잠금 파일이 남으면 다른 실행의 상태를 확인한 뒤 운영자가 복구하며, 도구가 임의로 잠금을 삭제하고 진행하지 않는다. 프로젝트 내부의 일반 디렉터리·일반 파일만 사용하며 외부 경로나 심볼릭 링크·junction을 통한 우회는 거절한다.

`.local/` 후보·백업은 공개 빌드에 포함하지 않는다. POSIX 파일 모드만으로 Windows 계정·ACL 격리 완료를 주장하지 않는다. 기존 서버 DB나 운영 데이터의 삭제·초기화는 하지 않는다.

## 자동 검증 범위

```powershell
node --test tests/community/today-cli.test.mjs
```

테스트는 주입된 응답과 테스트용 디렉터리만 사용한다. 승인 없는 실행 차단, 공통 후보 범위, 모델의 보류, 제공사·버전·옵션 불일치, fixture 게시 차단, KST 편집일, 중복·수정 탐지, 같은 날 변경 거절·부분 추가, 원본 백업, 안전한 경로와 원자적 파일 교체를 검증한다. 실제 모델·구독 계정의 이용 조건·운영 격리·실제 추천 생성·운영 배포의 통과 근거는 아니다.
