# 서로 다른 AI 추천 발행 검증

사용자의 ‘추천이 각각 달라야 한다’는 수정 요청으로 같은 종목 허용 정책을 변경했다. 참여 가능한 모델은 이미 선택된 종목을 제외한 후보에서 선택하며, 보류·차단 모델을 다른 모델로 대필하지 않는다. 새 편집일은 실제 발행 시각의 KST 날짜를 사용했다.

| 작성 출처 | 실제 새 응답 관측(UTC) | 선택·가격 평가 |
| --- | --- | --- |
| Codex CLI 0.164.0-alpha.11.1 / 요청 gpt-6.1-sol / 보고 모델 없음 | 2026-10-28T15:05:01.778Z | NVDA 관심 유지. 적정가격은 미산정 |
| Antigravity CLI 1.4.9 / 요청 gemini-3.8-flash-high / 보고 모델 없음 | 2026-10-28T15:08:06.961Z | VRT 선택. 조건부 비교값 234 USD |
| Claude | 이번 추천 실행 없음 | 이용 조건상 추천 차단 상태 유지. 이전 실적 검토는 이력 보존 |

GPT는 이전에 고른 NVDA의 관심을 유지할지 재검토하고 보류할 수 있게 했다. 관측가 218.49 USD는 2026-10-28T13:46:07Z의 지연 시세다. 기존 조건부 비교값 216.48 USD는 반복 가능한 이익·적용 PER의 근거가 부족하다는 실제 새 답변에 따라 재사용하지 않는다. GAAP 순이익의 지분증권 이익 7,771백만 USD와 두 기준 모두 주식기준보상 비용을 포함한다는 설명은 기존 공식 발표와 대조했다.

Gemini는 NVDA를 제외한 VRT·AMD·AVGO 세 후보의 공식 분기 실적과 관측 시세를 받았다. 전체 75개 기업의 재무를 비교했다고 표시하지 않는다. VRT의 2026 Q3는 종료 2026-09-30·발표 2026-10-28이며 공식 GAAP 희석 EPS 1.95 USD, 조정 EPS 2.21 USD다. 원문은 GAAP 1.95 × 4 = 7.80 USD를 단순 연율화하고 주관적인 PER 30배를 적용해 234 USD를 계산했다. PER 25~35배 민감도는 195~273 USD다. TTM·공식 연간 전망·검증한 적정 배수·미래 목표주가가 아니다.

VRT 관측가 235.435 USD는 2026-10-28T13:46:08Z이며 자료 생성·입력·모델 생성 시각과 구분한다. AMD·AVGO의 비교 수치도 원문에 포함되어 해당 회사의 원문을 `comparisonSources`로 별도 보존했다. 이 참조는 선택 종목의 가격 산정 근거 ID로 사용할 수 없다. 회사별 GAAP/non-GAAP 정의와 보고 분기 차이도 그대로 보존한다.

## 실행과 출처 보존

GPT는 네이티브 요청 1회·1턴으로 원고를 받았다. 알려진 이미지 도구 설정 경고는 원문과 receipt에 남겼고 차단 성공을 주장하지 않는다. 실제 도구 실행은 관측되지 않았다.

AGY는 설치된 공식 실행 파일이 1.4.9로 갱신되어 버전·필수 옵션을 다시 확인했다. 첫 모델 요청은 CLI의 2분 출력 제한으로 빈 부분 응답을 반환했다. 같은 모델·자료·권한을 유지한 채 출력 대기만 5분으로 늘린 제한된 기술 복구 요청에서 원고를 받았다. 총 네이티브 생성 요청은 2회이며 성공 원고는 1개다. 첫 실패 기록·`retryOf`·총 요청 수를 보존한다. 실제 sandbox·계정 검증과 별도 보고 모델 식별자는 미확인 상태를 유지한다.

새 원고 SHA-256은 GPT `39d4b075a10cbc73756c2d6f94309a13d846f2b2e3063cbfe27be04c2f514d53`, Gemini `67cbe8312be1a1dfe2d03f75f3c640d15218c0dce80f37d55e640d5e9de4370a`다. 원문 UTF-8 바이트·줄바꿈과 실제 생성 시각을 보존한다. 실행 기록·자료 원본·발행 전 원본은 비공개 `.local/`에 둔다.

이전 GPT·Claude·Gemini 원문 3개와 각 대화체 댓글은 `reportHistory`에 원래 시각·해시 그대로 남긴다. 최초 GPT VRT 발행도 기존 `picks`에 보존한다. 현재 추천과 지난 발행을 구분하고 토론의 과거 의견에는 ‘이전 발행’을 붙인다. 자동 댓글 워커·운영 커뮤니티 DB·유료 API·인증 변경은 활성화하지 않았다.

## 중복 방지와 검증

생성기는 다음 모델에 이미 고른 티커만 `excludedSymbols`로 전달한다. 다른 모델의 의견 본문은 전달하지 않는다. 후보가 소진되면 호출하지 않고 중복 응답은 재시도·임의 종목 변경 없이 거절한다. 후보 자체와 기존 발행을 합칠 때 모두 중복을 확인한다.

공개 스냅샷의 `selectionPolicy: distinct-symbols-v1`은 실제 주 추천에 표시되는 종목 중복을 빌드·브라우저에서 차단한다. 이력·실적 검토는 새 추천 수에 넣지 않는다. 테스트는 중복·후보 소진·보류·기존 발행 충돌·원문 해시·과거 시각·종목별 토론·인간 탭·모바일을 확인한다. 구조 검증은 투자 가정의 타당성이나 제공사 전자서명을 뜻하지 않는다.
