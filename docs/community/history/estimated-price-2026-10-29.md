# AI 추정 가격과 추천 조건 · 2026-10-29

사용자는 ‘적정가격’ 대신 ‘추정 가격’으로 표기하고 현재 시가보다 추정 가격이 높은 종목을 고르도록 요청했다. 화면의 필드·근거 제목·소개·검색 메타데이터를 **AI 추정 가격**으로 변경했다. 기존 `fairValue` 필드명과 실제 모델 원문·댓글·시각·해시·과거 발행은 그대로 보존한다.

## 화면에서 비교하는 기준

`getTodayPriceComparison()`은 현재 시세 스냅샷의 동일 종목·통화 가격과 실제 발행된 AI 추정값을 비교한다. 식은 `(AI 추정 가격 / 관측 시가 - 1) × 100`이다. 정상 조회된 시가보다 **엄격히 높을 때만** 상승 여력 조건 충족으로 집계한다. 낮거나 같으면 참고 의견·조건 미충족으로 표시하며 가격 미산정은 보류다. 시세 조회 실패·종목/통화 불일치·유효하지 않은 시각은 비교 불가이고 이전 확인값을 새 정상값으로 간주하지 않는다.

조회된 현재 시세가 바뀌면 비교 결과도 다시 계산한다. 장 마감 시세에는 관측 시각·지연 여부를 함께 표시하고 임의로 날짜를 갱신하지 않는다. 과거 원문은 당시 추정과 조건을 유지하며 현재 추천 수에 합치지 않는다. 이 비교는 가격 차이의 산술 조건이며 수익률 예측이나 추정 방법의 검증을 뜻하지 않는다.

현재 GPT NVDA 의견에는 새 가격 추정이 없다. 이전 Gemini VRT 추정값 **234 USD**는 버티브 관측 시가 242.94 USD보다 낮다. 이 숫자를 높이거나 민감도 상단을 대표값으로 바꾸지 않고 원문 전체를 이전 발행에 보존했다.

## Gemini의 실제 다른 종목 선택

사용자가 표시 변경만이 아닌 실제 재선정을 명시하여 공식 Gemini 웹에서 요청 **1회**로 새 의견을 받았다. 기존 GPT의 NVDA와 이전 Gemini의 VRT를 제외하고 공식 실적과 시세가 있는 AMD·AVGO 두 후보를 전달했다. 전체 75개 기업을 비교했다고 표현하지 않는다. 근거가 없으면 보류하고 원하는 결과가 나올 때까지 재생성하지 않는 조건이었다.

- 실제 선택: **브로드컴 AVGO**.
- 제공한 관측 시가: **351.81 USD**, 실제 관측 **2026-10-28T20:00:01Z**. 실시간 시세가 아니다.
- 실제 응답의 대표 추정: **375.20 USD**, 관측 시가 대비 **+6.648475%**(표시 +6.65%).
- 계산: FY2026 Q3 GAAP 희석 EPS **2.68 × 4 × 주관적 PER 35 = 375.20 USD**. 같은 기준의 배수 30~40 민감도는 **321.60~428.80 USD**다.
- 이는 단일 분기 수익력의 단순 지속·배수 가정이며 TTM·공식 연간실적·검증된 시장배수·상승 보장이 아니다. 가정이 달라지면 관측 시가보다 낮은 값도 나온다.

웹의 모델 메뉴에서 **3.1 Pro**를 선택했으며 서버의 실제 모델 식별자는 보고되지 않아 `reportedModel: null`이다. 출처는 `cliName: gemini-web`, 웹 앱 버전은 미공개이므로 `cliVersion: null`로 보존한다. Antigravity나 CLI가 생성한 새 결과로 표시하지 않는다. 공개 데이터에는 계정 이메일·개인 대화 URL을 넣지 않는다.

완성된 응답의 공식 ‘복사’ 버튼으로 얻은 텍스트를 보존했다. 해시 `9fe66c84bf2ff9aaf396fc04302dc61fd30e52ce292bf520c4843d5ff52f3ed7`는 이 복사 원문의 UTF-8 SHA-256이며 서버 응답 바이트나 제공사 전자서명을 검증한 것은 아니다. 실제 요청 시작은 **2026-10-29T03:14:41.872Z**, 복사 원문 기록은 **2026-10-29T03:17:14.602Z**다. 추정 기준시각은 입력자료 생성 **2026-10-29T02:07:53.177Z**로 생성·발행 시각과 구분한다.

공식 실적과 산식을 검수했다. 원문의 FCF ‘136억 USD’는 [공식 발표](https://investors.broadcom.com/news-releases/news-release-details/broadcom-inc-announces-third-quarter-fiscal-year-2026-financial)의 **13,665백만 USD = 136.65억 USD**로 별도 정정했다. 주식보상 **2,019백만 USD**와 인수 무형자산 상각 **2,006백만 USD**는 각각의 비용이며 GAAP에 포함된다. 원문에 있는 Markdown 형식 링크는 그대로 보존하고 공개 근거 링크는 확인된 공식 HTTPS URL로 따로 연결한다.

## Gemini 새 실행 제약

이번 작업에서 [Google Antigravity 공식 FAQ](https://antigravity.google/docs/faq)의 ‘Can I use Antigravity CLI headless mode in third-party coding agents or automate account switching?’ 항목을 다시 확인했다. 개인 구독의 `agy -p`를 타사 코딩 에이전트·앱에서 감싸 실행하는 방식은 지원하지 않는다고 명시한다. [추가 약관 §6](https://antigravity.google/terms)도 타사 도구로 서비스에 접근하는 방식을 제한한다. 문서 변경 시점은 확인하지 않았으므로 새로 생긴 제한이라고 주장하지 않는다.

따라서 기존 개인 구독 CLI를 다시 실행하지 않았고 위 재선정은 로그인된 **공식 Gemini 웹의 정상 입력창**에서 받았다. 이번 새 요청은 웹 1회, CLI 0회다. 기존에 보존된 실제 응답을 수정하거나 다른 모델의 글을 Gemini 결과로 표시하지 않는다. 유료 API 자동 전환·계정 회전·인증정보 복사·워커·DB 쓰기는 없다.
