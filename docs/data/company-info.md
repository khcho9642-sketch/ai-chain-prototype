# 신기업정보

기존 기업정보(#data)와 별도의 탐색 화면이다. 기본 진입점은 #company-info, 전체 비교는 #company-info?tab=all 이다. 핵심 50개사(상장 47·비상장 3)만 개별 분석·자료 페이지가 있으며 전체 586개사에 모두 포함된다. 이전 일반 기업 상세 주소는 해당 기업을 검색한 전체 목록으로 연결한다.

- 기업·섹터: 승인된 원본 ‘핵심기업 49’와 ‘회사리스트’를 회사 ID로 결합하고, 2026-11-08 사용자 요청의 Qualcomm(QCOM, C0371)을 AI 칩 핵심에 추가한다. 원본 `research/market/home-map-selection.json`과 시트명·SHA-256은 보존하며 `research/market/home-map-additions.json`의 추가만 원본 뒤 순서 50으로 합성한다. 전체 회사 수는 586개로 유지한다. 한 기업은 대표 섹터 하나에만 집계한다. 원장의 xAI/Grok 대리 행인 C0435(SpaceX)는 신기업정보에서 제외하고 테슬라(SCN038)를 독립 ID로 포함했다. 애플·테슬라는 전체에만 포함하며 자체 설계 칩 태그로 찾을 수 있다. 별도 원장과 기존 기업정보는 유지한다.
- 전체 표: 회사명, 섹터, 역할, 국가·거래소, 티커, 주가, 시가총액, 1일·1개월·연초 대비 등락률, 52주 고점 대비, 최근 4분기 매출, 매출 성장률, PER 등 14개 열을 기본 표시한다. 열 머리글을 누르면 정렬되며, 기본 순서는 상장사 시가총액 내림차순이다. 비상장 평가액과 결측은 시가총액 순위에서 제외된다. 값이 없는 행은 양방향 정렬에서 뒤에 둔다.
- 가격·재무: 주가는 확정 종가(현지통화), 시가총액과 매출은 억 달러다. 공통 거래 기준일과 환율 기준일은 표 아래, 매출 성장률 비교 기간은 셀 안에 표시한다. 확인된 적자는 PER 수치 대신 ‘적자’, 미확보 값은 대시로 표시한다. 비상장 투자 평가액에는 기준일과 공식 발표 링크가 붙는다.
- 탐색: 한국어·영문·티커·역할·태그로 검색하고 대표 섹터·국가·상장 여부로 범위를 좁힌다. 선택한 열·정렬·검색·필터·표시 행 수는 URL로 공유할 수 있다. 모바일에서도 같은 표를 좌우로 이동해 모든 열을 볼 수 있다.
- 운영: 공개 시장 자료는 검증한 data/company-market.json만 배포한다. 주 배포는 Cloudflare Pages, GitHub Pages는 보조 배포로 유지하고, 2026-11-07 시세 수집 중지 방침에 따라 저장한 비교표만 최초 한 번 읽는다. 자료의 기준일을 유지하며 자동 갱신하지 않는다. 비공개 DB나 수집 원본은 공개하지 않는다.

기업 목록 생성·검증: scripts/data/build-company-registry.mjs, assets/company-catalog.js. 표 산출과 데이터 검증: scripts/data/collect-company-market.mjs, assets/company-market-data.js. 변경 후 npm test와 npm run build로 검증한다.
