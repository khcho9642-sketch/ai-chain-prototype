# 신기업정보 운영

기존 기업정보와 시세 조회는 `#data`, 신기업정보 목록은 `#company-info`에서 연다. 기업 상세 주소는 `#company-info/company/{id}`다. `/analysis`, `/quote`, `/sources`를 붙여 공개 분석, 연결 종목 시세, 공식 자료를 직접 열 수 있다.

## 현재 목록

미리보기는 기업 재무 DB의 분석 대상 46개사와 기존 시장 지도를 회사 단위로 대조한 75개사를 사용한다. 이때 분석 대상 표식은 재무 DB의 수록 범위를 뜻한다. 공개 분석 수는 발행본을 기준으로 별도 집계한다. 정식 출시용 목록은 기획 검토를 거쳐 공개 500개사와 그 안의 핵심 46개사를 확정한다.

주 섹터는 시장 지도와 같은 9개 ID를 사용한다. 미리보기에서 재무 DB 수록 회사는 해당 DB의 분류와 연결한다. 아래 차이는 승인 원장 반영 시 확인할 대상이다.

| 회사 ID | 기업 | 재무 DB 분류 | 기존 시장 지도 분류 |
|---|---|---|---|
| C0582 | 한미반도체 | 반도체 소부장 | 파운드리·패키징 |
| C0543 | 삼성전자 | 파운드리·패키징 | 메모리 |
| C0024 | 알파벳 | 클라우드·GPU 컴퓨팅 | AI 모델 |

## 승인 원장 반영

1. 비공개 JSON 입력에 `status: "approved"`, 검토자 `reviewer`, 승인일 `approvedAt`을 기록한다. `companies`에는 공개 회사와 공식 출처를, `selections`에는 핵심 회사 ID·선정 이유·표시 순서를 넣는다. 복수 상장 종목은 한 회사의 `listings`에 모은다. 비상장사의 목록은 빈 배열로 둔다.
2. `editions`에 회사 ID, 편집 상태, 기준일, 검토자, 공개일, 갱신일, 결론과 네 부분 본문, 인용 출처를 넣는다. 지표에는 기간·범위·단위·값·출처를 기록하고 금액에는 통화를 붙인다. 미공개 값은 JSON `null`로 저장한다. 수정 중에는 마지막 공개본과 새 초안을 함께 두어 기존 공개본을 유지한다.
3. Node.js 24에서 프로젝트 루트를 기준으로 아래 명령을 순서대로 실행한다. `<private-release.json>`과 `<path-to-financials.sqlite>`을 실제 입력 파일 경로로 바꾼다.

```sh
node scripts/data/publish-company-catalog.mjs <private-release.json> --check
node scripts/data/publish-company-catalog.mjs <private-release.json>
node scripts/data/export-company-financials.mjs --db <path-to-financials.sqlite>
npm test
npm run build
```

첫 명령은 공개 500개사, 핵심 46개사, 섹터·회사 연결과 발행 자료를 검증한다. 두 번째 명령은 검증한 공개 필드만 `assets/company-approved-catalog.js`에 기록한다. 검토 입력은 공개 경로 밖에서 보관한다. 재무 DB를 갱신했을 때 세 번째 명령으로 기업별 최근 최대 5개 회계연도의 실적 자료를 다시 만든다. 회사 전체·연결·별도·사업부 범위와 출처는 자료의 표시 단위에 맞춰 확인한다.

## 화면 확인

- `npm run dev`로 실행해 `#data`와 `#company-info`를 각각 연다. 시장 지도에서 한미반도체를 선택한 뒤 기업 상세에서 같은 ID 및 차트 종목 `042700.KS`를 확인한다.
- 모바일 너비 360px에서 검색과 필터를 함께 적용하고 ‘더 보기’로 결과를 늘린다. 기업명으로 상세를 연 뒤 ‘목록으로’와 브라우저 뒤로 가기를 각각 사용해 검색 조건, 노출 개수, 보던 위치를 확인한다.
- 비상장사에서 기본정보·공식 자료를 확인하고, 복수 상장사에서는 거래 종목을 바꿔 거래소·통화가 일치하는지 본다. 공시나 시세 요청을 차단한 상태에서도 기업 개요가 열려야 한다.
- 승인본 반영 후 핵심 탭의 9개 섹터 합계와 발행 수를 각각 대조한다. 공개 분석에는 자료 기준일, 검토자, 기간·수치·단위·원문이 표시돼야 한다. 미발행 핵심 기업의 `/analysis`에서는 기본정보가 열려야 한다. 일반 기업은 같은 섹터의 핵심 기업으로 이동할 수 있다.
