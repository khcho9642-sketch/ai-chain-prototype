# 챕터 메뉴 위 공통 지수 띠

2026-11-08 사용자 요청으로 주요 지수 5개를 모든 챕터 바깥의 공통 영역에 표시한다. `index.html`의 `<body>` 직후, 기존 `<header>` 앞에 배치한다. PC에서는 한 줄로, 작은 화면에서는 가로 스크롤로 제공한다.

| 표시 | 저장 종목 코드 |
| --- | --- |
| 나스닥 | `^IXIC` |
| S&P 500 | `^GSPC` |
| 반도체(SOX) | `^SOX` |
| 코스피 | `^KS11` |
| 코스닥 | `^KQ11` |

`assets/index-strip-core.js`가 저장된 스냅샷만 해석한다. `assets/index-strip.js`는 대시보드의 `window.aiChainSnapshot`, `market-snapshot`, `market-snapshot-error`를 재사용한다. 별도 다운로드·API·구독·타이머·수집 명령은 없다. `assets/site-runtime.js`의 `realtimeEnabled = false`를 유지한다.

확정 종가와 직전 종가로 같은 관측의 등락률을 계산하고 원래 출처·종가일·수집 시각·오류를 보존한다. 옛 장중 가격을 종가로 승격하지 않으며, 일별 이력에서 파생할 때도 원래 수집일 이전의 현지 거래일만 사용한다. `daily-bar-start` 시각을 마감 시각으로 표시하지 않는다. 저장된 SOX 자료가 없으면 `—`로 남긴다. 샘플 숫자나 현재 장 상태를 채우지 않는다.

## 구현 검증과 운영 반영 구분

- 의미 검증: `tests/market/index-strip.test.mjs`의 고정 순서·결측·종가 해석·이전값·출처 보존·DOM 연결·추가 요청 차단 검사.
- 초기 작업 사본은 운영본과 달랐다. 운영 배포 `47729716-b445-4eec-8554-78f4b8558c5b`의 파일 목록 90개를 관리 화면에서 확인하고, 같은 불변 배포 주소에서 공개 파일을 대조했다.
- 배포 후보는 기존 `index.html`에 CSS·공통 띠·모듈을 삽입하고 신규 지수 파일 3개만 추가한다. 다른 기존 파일 89개와 저장 자료·실시간 중지 설정·회사 표의 해시를 그대로 보존한다. 기존 `_headers` 규칙도 동일하게 포함한다.
- 후보와 파일별 검증 근거는 `.local/releases/index-strip/`에 보관한다. 이 파일들을 소스의 공개 데이터 허용목록에 추가하지 않는다. 전체 로컬 `dist/`를 기존 운영본과 같다고 간주하지 않는다.
- 2026-11-08 준비 시점에 코드·빌드·공통 위치와 다른 챕터에서의 표시를 확인했다. Cloudflare 미리보기 업로드는 Chrome 파일 업로드 중 연결이 끊겨 완료되지 않았다. 업로드 진단 안내에 따라 확장 프로그램의 파일 URL 접근 설정 확인이 필요하다. 운영 배포·커밋·푸시는 수행하지 않았다.

재개할 때는 기존 Cloudflare 업로드 화면과 후보 ZIP을 먼저 확인한다. 완료된 배포로 오인하거나 현재 운영 파일을 이전 작업 사본으로 덮어쓰지 않는다.
