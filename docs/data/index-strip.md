# 홈 제목 오른쪽의 소형 저장 지수

2026-11-08 사용자 후속 요청으로 나스닥·S&P 500·SOX·코스피·코스닥 5개 저장 지수를 홈의 큰 **AI 시장 지도** 제목 오른쪽에 작게 표시한다. 홈에서만 보이며 다른 챕터로 이동하면 숨기고, 홈에 돌아오면 같은 저장값을 다시 보여준다. PC에서는 제목과 같은 줄에 배치하고, 모바일에서도 제목 오른쪽의 제한된 폭 안에서 지수를 가로로 넘겨 볼 수 있다.

각 지수에는 이름·저장값·등락률을 간결하게 표시한다. 각 카드의 **자료** 버튼은 기본 `<details>`·`<summary>`로 동작하며 종가일·출처·수집 시각·오류를 펼쳐 확인할 수 있다. 자료를 펼치는 동작은 추가 조회를 실행하지 않는다.

| 표시 | 저장 종목 코드 |
| --- | --- |
| 나스닥 | `^IXIC` |
| S&P 500 | `^GSPC` |
| 반도체(SOX) | `^SOX` |
| 코스피 | `^KS11` |
| 코스닥 | `^KQ11` |

`index.html`의 지수 요소는 `#v-home`의 light DOM 자식이며 `slot="home-indices"`로 연결한다. `assets/home-map.js`의 열린 Shadow DOM 안에서 제목 오른쪽의 같은 이름 슬롯에 표시한다. 이 연결로 기존 지수 모듈과 전역 스타일을 재사용한다.

`assets/index-strip-core.js`가 저장된 스냅샷만 해석한다. `assets/index-strip.js`는 대시보드의 `window.aiChainSnapshot`, `market-snapshot`, `market-snapshot-error`를 재사용한다. 별도 다운로드·API·구독·타이머·수집 명령은 없다. `assets/site-runtime.js`의 `realtimeEnabled = false`와 `MARKET_DATA_POLICY`의 수집·실시간·자동 재조회 중지를 유지한다.

확정 종가와 직전 종가로 같은 관측의 등락률을 계산하고 원래 출처·종가일·수집 시각·오류를 보존한다. 옛 장중 가격을 종가로 승격하지 않으며, 일별 이력에서 파생할 때도 원래 수집일 이전의 현지 거래일만 사용한다. `daily-bar-start` 시각을 마감 시각으로 표시하지 않는다. 저장된 SOX 자료가 없으면 `—`로 남긴다. 샘플 숫자나 현재 장 상태를 채우지 않는다.

## 현재 변경의 검증과 운영 반영

- `tests/market/index-strip.test.mjs`는 고정 순서·결측·종가 해석·이전값·출처와 날짜 보존·홈 슬롯 연결·추가 요청 차단을 검사한다.
- `tests/browser-smoke.py`와 `tests/home-browser-smoke.py`는 홈 H1 오른쪽의 작은 배치·모바일 가로 스크롤·다른 챕터에서 숨김·홈 복귀 시 저장값 보존을 검사한다. 기존 API·이벤트 구독·자동 재조회 중지 검사도 유지한다.
- 문서에 설명한 화면 기준과 실제 검사·빌드·운영 배포 성공은 구분한다. 배포는 최신 main을 반영한 작업 사본의 검증된 빌드로 수행하고 결과를 별도 기록한다.

## 과거 상단 공통 띠 준비 기록

아래는 홈 제목 옆으로 옮기기 전의 초기 준비·업로드 시도 이력이다. 당시 파일 수·해시·실패 상태를 보존하며 현재 배치나 배포 재개 지침으로 사용하지 않는다.

- 초기 작업 사본은 운영본과 달랐다. 운영 배포 `47729716-b445-4eec-8554-78f4b8558c5b`의 파일 목록 90개를 관리 화면에서 확인하고, 같은 불변 배포 주소에서 공개 파일을 대조했다.
- 배포 후보는 기존 `index.html`에 CSS·공통 띠·모듈을 삽입하고 신규 지수 파일 3개만 추가한다. 다른 기존 파일 89개와 저장 자료·실시간 중지 설정·회사 표의 해시를 그대로 보존한다. 기존 `_headers` 규칙도 동일하게 포함한다.
- 후보와 파일별 검증 근거는 `.local/releases/index-strip/`에 보관한다. 이 파일들을 소스의 공개 데이터 허용목록에 추가하지 않는다. 전체 로컬 `dist/`를 기존 운영본과 같다고 간주하지 않는다.
- 2026-11-08 준비 시점에 코드·빌드·공통 위치와 다른 챕터에서의 표시를 확인했다. Cloudflare 미리보기 업로드는 Chrome 파일 업로드 중 연결이 끊겨 완료되지 않았다. 업로드 진단 안내에 따라 확장 프로그램의 파일 URL 접근 설정 확인이 필요하다. 운영 배포·커밋·푸시는 수행하지 않았다.

> 당시 재개 안내: 기존 Cloudflare 업로드 화면과 후보 ZIP을 먼저 확인한다. 완료된 배포로 오인하거나 현재 운영 파일을 이전 작업 사본으로 덮어쓰지 않는다.

현재 공통 기준은 GitHub의 최신 main이다. 과거 후보 ZIP이나 특정 컴퓨터의 임시 경로를 최신 운영 소스로 가정하지 않는다.
