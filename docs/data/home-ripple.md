# 홈 업종 가중방식과 오늘의 파급

홈 `#home`의 히트맵·버블은 기존 9개 섹터를 유지하며 전체 회사 원장 586개사(상장 537개·비상장 49개)를 대상으로 실제 수집값을 연결한다. 업종 카드와 파급 계산은 계속 `assets/home-focus.js`의 핵심 45종목(기존 섹터 순서별 5개)만 사용한다. 전체 지도, 핵심 카드와 이미 발행된 심층분석 수는 서로 다른 범위다. 신규 라우트나 프레임워크 전환은 없다.

## 업종 카드

- 기본은 기존과 같은 최근90일·동일가중이다. 카드 기간은1거래일·1주·1개월·3개월·1년 중 변경할 수 있으며 하단 지도 기간과 독립적이다.
- 유효 종목의 공통 현지 거래일을 맞춘 종가 수익률을 동일 비중으로 평균한다.1거래일은 실제 공통 거래일2개를 비교하므로 월요일에 주말 가격을 만들지 않는다.
- 시총가중은 **정확히 기간 시작일로 표시된 제공처 시총**만 사용한다. KRW·JPY·TWD 시총은 동일 날짜의 USD기준 환율로 환산한다. 현재 시총·가까운 분기 말 시총·현재 주식 수 역산으로 결측을 채우지 않는다.
- 날짜나 환율이 없으면 해당 종목은 시총가중에서 제외하고 `*`, 반영 종목 수와 이유를 표시한다. 전부 없으면 `— *`다. 실제 수집 확인 시45개사 모두 시총 이력이 있었으나1거래일 가중에 사용 가능한 날짜·환율 조합은31개였다. 기간과 수집본에 따라 바뀐다.
- 두 방식이 같은 종목 집합을 사용할 때만 차이가3%p 이상이면 쏠림 태그를 붙인다. 서로 다른 표본으로 대형주 효과를 단정하지 않는다.
- 가중방식만 브라우저에 저장하며 저장 접근에 실패하면 동일가중으로 동작한다.

## 오늘의 파급

1.45개 종목의 마지막 완료 거래일1일 등락률에서 절댓값2% 이상인 상위3개를 고른다.
2. 종목의 발행국이 아니라 **실제 상장 시장**으로 한미 시차를 맞춘다. 미국 ADR은 미국 거래일을 사용한다.
3. 미국 종목의 움직임에는 다음 관측 한국 거래일을, 한국 종목에는 같은 현지 날짜의 미국 종가를 연결한다. 미도착 종가와 누락된 개별 종가를 임의의 다음 날짜로 대체하지 않는다.
4. 최근60거래일 중 트리거 절대수익률2% 이상인 날의 같은 방향 비율을 계산한다. 양쪽 날짜가 확인된 표본을 분모로 쓰며 표본 수·누락 수를 보존한다. 표본5개 미만은 `동조율 —`, 알려진 비율50% 미만은 제외한다.
5. 섹터 순서에 따라 상류·동일 섹터와 하류에 최대3개씩 표시한다. 이는 함께 움직인 관측이며 납품 관계·원인·미래 움직임을 증명하지 않는다.

각 노드에 시장·현지 거래일·등락률·동조율을 표시한다. 미국→한국 날짜는 구간 상단에 함께 표시한다. 연결을 누르면 기존 기업정보로 이동한다.820px이하는 상류→트리거→하류 세로 배치다.

## 실제 히트맵과 버블

`assets/home-map-universe.js`의 전체 586개 회사 식별 목록을 `assets/home-map-data.js`가 같은 시장 스냅샷에 연결한다. 회사 ID·이름·국가·주 섹터·상장 상태·정규화한 상장 종목만 공개하며 예시 `cap`·`day`·합성 수익률은 계산에 사용하지 않는다. 원장이나 상장 연결이 바뀌면 `node scripts/data/build-home-map-universe.mjs`로 이 식별 모듈을 다시 만든다. 원본 Excel·비공개 분석·원천 관측값은 이 모듈에 포함하지 않는다.

회사마다 대표 상장을 우선하고 실제 종가·시총·환율이 함께 유효한 대체 상장이 있을 때 그 종목을 사용한다. ADR·본주·복수 상장을 합산하지 않고 회사 ID당 하나의 면적만 만든다. 비상장 49개와 대표 상장 미연결 12개도 전체 대상과 사유에 남긴다. 미연결 회사에 유효한 대체 상장이 있으면 대표 상장 미확인 상태를 보존한 채 사용할 수 있다. 공급처 조회 성공은 신규 티커의 회사 동일성 검증을 뜻하지 않는다.

| 화면 요소 | 실제 계산 기준 |
|---|---|
| 히트맵 타일 면적·버블 원 면적 | 제공처의 최근 관측 시총을 USD로 환산. `provider-current` 시총과 원래 관측 시각을 보존 |
| 히트맵 색·버블 색과 세로 위치 | 선택한 1일·1주·1개월·1년의 완료 일봉 종가 수익률 |
| 시총 환율 | 시총 관측 시점보다 늦지 않은 최신 확정 환율. 최대 7일 이내 관측만 허용하고 적용 환율 날짜를 별도 보존 |
| 시총·통화·환율·확정 종가 미확보 | 면적을 임의로 만들지 않고 지도에서 제외. 대상 수·반영 수·제외 사유 표시 |
| 선택 기간의 수익률만 미확보 | 히트맵은 중립색과 `—`, 세로 위치를 정할 수 없는 버블은 제외. 0%로 대체하지 않음 |
| 이전 수집값 | 원래 종가 기준일·시총 관측 시각·환율 날짜를 유지하고 이전값 상태 표시 |

1일 수익률은 해당 시장의 마지막 완료 거래일과 직전 거래일 종가를 비교한다. 1주·1개월·1년은 각각 7일·30일·365일 전 기준의 실제 거래일 종가를 사용하며 휴장 정렬은 최대 7일만 허용한다. 개별 회사의 필요한 기준 종가가 없으면 다른 날짜로 임의 대체하지 않는다. 종가 수집은 1년 비교 기준일을 확보하도록 380일의 일봉을 요청하며 실제 조회 시작·종료 시각은 `historyWindow`에 보존한다.

지도 크기는 **최근 관측 시총**이며, 업종 카드의 **기간 시작일 시총가중**과 기준이 다르다. 기간을 바꾸면 수익률 색상·위치가 바뀌지만 크기를 과거 시총으로 되돌리지는 않는다. 툴팁·선택 기업에서 종가 기준일, 시총 관측 시각, 환율 적용일과 출처를 확인할 수 있다. 이 값들을 같은 시각의 확정 시총이라고 표시하지 않는다.

## 수집과 배포

`npm run collect`가 원장에 연결된 555개 고유 종목·지표의 종가와 현재 관측 시총을 수집한 뒤 핵심 45종목의 제공처 날짜별 시총과 23개 비달러 통화의 환율 이력을 보강한다. 환율은 KRW·JPY·TWD·EUR·CHF·HKD·SGD·CNY·AED·AUD·BRL·CAD·IDR·INR·MYR·NZD·QAR·SAR·SEK·THB·TRY·DKK·GBP의 **통화 단위/USD 1달러** 방향이다. CHF는 `USDCHF=X`, 나머지는 명시적 `통화코드=X` 종목을 사용하며 반대 방향 환율을 암묵적으로 대입하지 않는다. 실제 시총의 확인된 통화는 최초 검증본 기준 USD와 비달러 21개였으며, DKK·GBP 환율 수집은 해당 통화 시총의 결측·모호함을 해소하지 않는다. GBp·ILA·ZAc 등 가격의 세부 단위만으로 시총 통화를 재지정하지 않는다.

날짜별 시총은 12시간 캐시하고 실패 시 기존 이력과 실제 관측 시각을 보존한다. 환율 실패도 이전 관측값·날짜·상태를 보존하며 보조 자료 실패가 종가를 지우지 않는다.

`npm run build:ripple`이 같은 `data/market.json`에서60거래일 동조율을 미리 계산해 `data/ripple.json`을 원자적으로 만든다. `--allow-unavailable`은 자료 부족을 비어 있는 명시적 상태로 출력하는 배포용 옵션이다. Pages 수집 직후 생성하며 브라우저에서는 모델/API를 호출하거나 동조율을 다시 계산하지 않는다.

빌드는 시장 수집 ID가 정확히 일치하는 파급 파일만 채택하고, 누락·손상·다른 수집본이면 현재 시장 파일에서 다시 생성한다. Vercel 배포 준비도 내려받은 동일 시장 파일에서 파급을 만든다. API는 고정 공개 파일로 이동하고, 조회 실패·기준일 불일치는 이전값 안내와 날짜를 보존한다. 공개 허용목록에 `ripple.json`만 추가하며 원장·수집 근거·개인 파일은 정적 배포에 포함하지 않는다.

## 검증

가중·환율·시총 결측·3%p 경계·휴장·미완료 봉, 한미 날짜 매칭·동조율 표본·50% 필터·원자적 저장을 단위 검증한다. 지도는 586개 고유 회사·537개 상장·49개 비상장 보존, 대표·대체 상장 중복 방지, 실제 USD 시총 변환, 환율 날짜, 4개 기간의 종가 수익률, 결측·이전값 처리와 합성값 미사용도 검증한다. 브라우저 검사는 데스크톱·820px·390px에서 토글·저장·파급 선택·기업 이동·히트맵·버블·검색·필터·가로 넘침·콘솔 오류를 확인한다. 검증용 임의 가격은 브라우저 응답에만 주입하며 공개 파일에 저장하지 않는다.
