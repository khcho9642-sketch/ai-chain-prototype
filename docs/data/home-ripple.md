# 홈 업종 가중방식과 오늘의 파급

홈 `#home`의 기존9개 섹터·히트맵·버블을 유지한다. 새 카드와 파급 계산은 `assets/home-focus.js`의 핵심45종목(기존 섹터 순서별5개)만 사용한다. 회사 원장의586개사 전체와 이미 발행된 심층분석 수는 이45종목 관측 바스켓과 별개다. 신규 라우트나 프레임워크 전환은 없다.

## 업종 카드

- 기본은 기존과 같은 최근90일·동일가중이다. 카드 기간은1거래일·1주·1개월·3개월·1년 중 변경할 수 있으며 하단 지도 기간과 독립적이다.
- 유효 종목의 공통 현지 거래일을 맞춘 종가 수익률을 동일 비중으로 평균한다.1거래일은 실제 공통 거래일2개를 비교하므로 월요일에 주말 가격을 만들지 않는다.
- 시총가중은 **정확히 기간 시작일로 표시된 제공처 시총**만 사용한다. KRW·JPY·TWD 시총은 동일 날짜의 USD기준 환율로 환산한다. 현재 시총·가까운 분기 말 시총·현재 주식 수 역산으로 결측을 채우지 않는다.
- 날짜나 환율이 없으면 해당 종목은 시총가중에서 제외하고 `*`, 반영 종목 수와 이유를 표시한다. 전부 없으면 `— *`다. 실제 수집 확인 시45개사 모두 시총 이력이 있었으나1거래일 가중에 사용 가능한 날짜·환율 조합은31개였다. 기간과 수집본에 따라 바뀐다.
- 두 방식이 같은 종목 집합을 사용할 때만 차이가3%p 이상이면 쏠림 태그를 붙인다. 서로 다른 표본으로 대형주 효과를 단정하지 않는다.
- 가중방식만 브라우저에 저장하며 저장 접근에 실패하면 동일가중으로 동작한다.

## 오늘의 파급

1.45개 종목의 마지막 완료 거래일1일 등락률에서 절댓값2% 이상인 상위3개를 고른다.
2. 종목의 발행국이 아니라 **실제 상장 시장**으로 한미 시차를 맞춘다. 미국 ADR은 미국 거래일을 사용한다.
3. 미국 종목의 움직임에는 다음 관측 한국 거래일을, 한국 종목에는 같은 현지 날짜의 미국 종가를 연결한다. 미도착 종가와 누락된 개별 종가를 임의의 다음 날짜로 대체하지 않는다.
4. 최근60거래일 중 트리거 절대수익률2% 이상인 날의 같은 방향 비율을 계산한다. 양쪽 날짜가 확인된 표본을 분모로 쓰며 표본 수·누락 수를 보존한다. 표본5개 미만은 `동조율 —`, 알려진 비율50% 미만은 제외한다.
5. 섹터 순서에 따라 상류·동일 섹터와 하류에 최대3개씩 표시한다. 이는 함께 움직인 관측이며 납품 관계·원인·미래 움직임을 증명하지 않는다.

각 노드에 시장·현지 거래일·등락률·동조율을 표시한다. 미국→한국 날짜는 구간 상단에 함께 표시한다. 연결을 누르면 기존 기업정보로 이동한다.820px이하는 상류→트리거→하류 세로 배치다.

## 수집과 배포

`npm run collect`가 기존555개 종목·지표 종가를 수집한 뒤 핵심45종목의 제공처 날짜별 시총과3개 환율 이력을 보강한다. 날짜별 시총은12시간 캐시하고 실패 시 기존 이력과 실제 관측 시각을 보존한다. 보조 자료 실패가 종가를 지우지 않는다.

`npm run build:ripple`이 같은 `data/market.json`에서60거래일 동조율을 미리 계산해 `data/ripple.json`을 원자적으로 만든다. `--allow-unavailable`은 자료 부족을 비어 있는 명시적 상태로 출력하는 배포용 옵션이다. Pages 수집 직후 생성하며 브라우저에서는 모델/API를 호출하거나 동조율을 다시 계산하지 않는다.

빌드는 시장 수집 ID가 정확히 일치하는 파급 파일만 채택하고, 누락·손상·다른 수집본이면 현재 시장 파일에서 다시 생성한다. Vercel 배포 준비도 내려받은 동일 시장 파일에서 파급을 만든다. API는 고정 공개 파일로 이동하고, 조회 실패·기준일 불일치는 이전값 안내와 날짜를 보존한다. 공개 허용목록에 `ripple.json`만 추가하며 원장·수집 근거·개인 파일은 정적 배포에 포함하지 않는다.

## 검증

가중·환율·시총 결측·3%p 경계·휴장·미완료 봉, 한미 날짜 매칭·동조율 표본·50% 필터·원자적 저장을 단위 검증한다. 브라우저 검사는 데스크톱·820px·390px에서 토글·저장·파급 선택·기업 이동·기존 지도·가로 넘침·콘솔 오류를 확인한다. 검증용 임의 가격은 브라우저 응답에만 주입하며 공개 파일에 저장하지 않는다.
