## 업종 카드

- 유효 종목의 공통 현지 거래일을 맞춘 종가 수익률을 동일 비중으로 평균한다.1거래일은 실제 공통 거래일2개를 비교하므로 월요일에 주말 가격을 만들지 않는다.

- 날짜나 환율이 없으면 해당 종목은 시총가중에서 제외하고 `*`, 반영 종목 수와 이유를 표시한다. 전부 없으면 `— *`다. 승인 목록에 새로 포함된 종목도 실제 날짜별 시총이 보관되어 있어야 가중치에 들어가며 반영 수는 기간과 수집본에 따라 바뀐다.

- 가중방식만 브라우저에 저장하며 저장 접근에 실패하면 동일가중으로 동작한다.

## 실제 히트맵과 버블

`assets/home-map-universe.js`의 승인 52개 회사 식별 목록을 `assets/home-map-data.js`가 같은 시장 스냅샷에 연결한다. 회사 ID·이름·국가·주 섹터·상장 상태·승인 티커·역할을 공개하며 예시 `cap`·`day`·합성 수익률은 계산에 사용하지 않는다. 승인 선택이나 연결이 바뀌면 `node scripts/data/build-home-map-universe.mjs`로 이 식별 모듈을 다시 만든다. 원본 Excel·비공개 분석·원천 관측값은 이 모듈에 포함하지 않는다.

각 회사는 원본 시트와 명시적인 사용자 추가 근거에 지정된 종목만 사용한다. QCOM은 사용자 추가 근거의 `QCOM`, CXMT는 `688825.SS` 티커를 사용한다. 예를 들어 ASML은 `ASML.AS`, TSMC는 `2330.TW`, SMIC는 `0981.HK`, GDS는 `GDS`, 알리바바는 `BABA`다. 지정 티커의 종가·시총이 없으면 결측 사유를 남기며 다른 상장 종목으로 대체하지 않는다. 회사 ID당 하나의 면적만 만들고, 비상장 4개는 52개 대상과 사유에 남긴다. 공급처 조회 성공은 신규 티커의 회사 동일성 검증을 뜻하지 않는다.

CXMT의 상장 코드 `688825`는 [회사 공식 소개](https://www.cxmt.com/en/about.html)와 [상하이거래소 상장 공고](https://www.sse.com.cn/disclosure/announcement/listing/ipo/c/c_20260724_10826610.shtml)로 확인하며, 제공처 연결 티커는 `688825.SS`다. 기존 저장본에 CXMT 종가·시총·기간 수익률이 없으면 결측 사유를 유지한다. 상장 확인을 가격 관측으로 취급하거나 새 시세를 수집하지 않는다.

Nscale의 국가·회사 식별은 사용자 신규 원장에 보존한다. [공식 서비스 소개](https://www.nscale.com/service-overview)를 근거로 클라우드·GPU 컴퓨팅에 분류한다. [IPO 신청 발표](https://www.nscale.com/press-releases/nscale-files-initial-public-offering)의 `NSCL`은 제안 티커이며, 작업 시점 [SEC 제출 메타데이터](https://data.sec.gov/submissions/CIK0002110365.json)의 `tickers`·`exchanges`가 빈 배열인 상태를 기준으로 비상장으로 둔다. `NSCL`을 상장 티커나 시세 조회 대상으로 연결하지 않는다. 공개 종가·시총·가격 이력은 미확보 상태로 남기며 원래 586개·555종목 스냅샷과 실제 관측 날짜를 새 등록일로 덮어쓰지 않는다.

## 보관 자료와 배포

수집 중지 전 `npm run collect`는 원장에 연결된 555개 고유 종목·지표의 종가와 관측 시총을 수집한 뒤 승인 상장 46종목의 제공처 날짜별 시총과 23개 비달러 통화의 환율 이력을 보강했다. 현재 이 수집을 실행하지 않으며 누락 이력을 임의 생성하지 않는다. 환율은 KRW·JPY·TWD·EUR·CHF·HKD·SGD·CNY·AED·AUD·BRL·CAD·IDR·INR·MYR·NZD·QAR·SAR·SEK·THB·TRY·DKK·GBP의 **통화 단위/USD 1달러** 방향이다. CHF는 `USDCHF=X`, 나머지는 명시적 `통화코드=X` 종목을 사용하며 반대 방향 환율을 암묵적으로 대입하지 않는다. 실제 시총의 확인된 통화는 최초 전체 수집 검증본 기준 USD와 비달러 21개였으며, DKK·GBP 환율 수집은 해당 통화 시총의 결측·모호함을 해소하지 않는다. GBp·ILA·ZAc 등 가격의 세부 단위만으로 시총 통화를 재지정하지 않는다.

날짜별 시총은 12시간 캐시하고 실패 시 기존 이력과 실제 관측 시각을 보존한다. 환율 실패도 이전 관측값·날짜·상태를 보존하며 보조 자료 실패가 종가를 지우지 않는다.

`npm run build:ripple`이 같은 `data/market.json`에서60거래일 동조율을 미리 계산해 `data/ripple.json`을 원자적으로 만든다. `--allow-unavailable`은 자료 부족을 비어 있는 명시적 상태로 출력하는 배포용 옵션이다. 현재는 저장된 시장 파일을 바탕으로만 생성하며 새 시세 수집을 실행하지 않는다. 브라우저에서는 모델/API를 호출하거나 동조율을 다시 계산하지 않는다.

빌드는 시장 수집 ID와 승인 명단이 정확히 일치하는 파급 파일만 채택하고, 누락·손상·다른 수집본이면 보관된 시장 파일에서 다시 생성한다. Pages는 `main` 변경과 수동 배포로만 게시하고 시간 예약·새 시세·3년 주가 이력 수집을 실행하지 않는다. 기타 자료 작업은 기존 push·수동 배포 절차를 유지한다. 조회 실패·기준일 불일치는 이전값 안내와 날짜를 보존한다. 공개 허용목록에 경량 표시본과 파급 파일을 명시하며 원장·수집 근거·개인 파일은 정적 배포에 포함하지 않는다.
