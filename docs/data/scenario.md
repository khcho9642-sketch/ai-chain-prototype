# 시나리오 분석

## 사용 흐름

사이트의 `#scenario`에서 한 가지 변화와 크기, 지속기간을 선택하면 9개 섹터와 주요 기업의 조건부 가치 변화를 계산한다. 사람이 입력값을 정하며, 강세·중립·약세 서사를 자동 선택하지 않는다. 기존 Today·시세·지도·커뮤니티 경로를 유지한다.

시나리오는 금리 변화(%p), AI CAPEX 변화(%), HBM 가격·공급 변화(각각 %), GPU·데이터센터 임대료 변화(각각 %), 모델매출 성장률 변화(기준 연간 성장률과 변경 성장률)다. CAPEX는 확대와 축소를 모두 지원한다. HBM 가격과 물량, GPU 요금과 데이터센터 공간·전력 임대료를 서로 동일한 충격으로 취급하지 않는다.

9개 섹터는 반도체 소부장 / 파운드리·패키징 / 메모리 / AI 칩 / AI 장비 / 전력·냉각 / 데이터센터 / 클라우드·GPU 컴퓨팅 / AI 모델이다. 이 챕터는 사용자가 확정한 9개 SEG를 사용하며, 기존 8개 고리 시세·지도 분류를 재사용하지 않는다.

애플, 마이크로소프트, 엔비디아, 아마존, 알파벳, 메타, 테슬라는 항상 표시한다. 주요 기업만 포함하며 여러 섹터에 속한 기업의 전사 가치는 회사 ID별로 한 번 계산한다. 섹터 소속은 실제 매출 비중을 뜻하지 않는다. 테슬라와 xAI는 합치지 않는다.

## 계산값과 실제 자료의 구분

초기 모델의 재무 비율·사업 노출도·전파 계수는 기능 설명과 민감도 탐색을 위한 **명시적 가정**이다. 기업의 감사된 재무제표나 회귀 추정으로 보정된 계수라고 표시하지 않는다. 회사별 기준매출을 100으로 정규화해 현금흐름을 산정하고 기준 기업가치 지수 100 대비 변화를 보여준다. 실제 기업가치의 절대 금액은 이 정규화 지수에서 얻을 수 없다.

관측시가는 기존 공개 시세 스냅샷의 종목·통화·관측시각·출처와 함께 표시한다. 정상 상태이며 양수인 관측값만 환산에 사용한다. 관측시가에 가정 기반 지분가치 변화비율을 곱한 값은 **관측시가 기준 환산주가**이며, DCF 절대 내재주가·실제 미래 주가·보장된 수익률이 아니다. 현재 시세와 과거 관측시세를 혼동하지 않는다. 시세를 못 읽으면 계산 자체는 유지하되 가격은 미연결로 남긴다. 비상장 AI 모델 회사에 상장주가를 만들지 않는다.

기업별 가정을 변경할 수 있으며 변경된 가정과 적용 입력은 결과에 유지한다. 사용자가 지정하지 않은 실제 시장점유율·계약단가·재무 수치를 자동 생성하지 않는다.

## 현재 계산 범위

현재 구현은 정규화된 기준 현금흐름에 물량·판매단가·단위원가·추가 CAPEX를 별도로 반영하는 8년 민감도 모형이다. 회사별 계약, 재고, 생산 병목, 대체 공급자, 실제 세율·운전자본을 입력한 완전한 재무제표 모형은 아니다. 전파 계수와 시차는 설명용 가정이며, 실측 자료로 보정되지 않았다. 가장 긴 입력 기간과 전파 시차가 끝난 이후에 잔존가치를 계산한다.

## 전파와 가치평가 원칙

- 외부 입력에서 수요·가격·원가·설비투자·공급제약을 계산하고 현금흐름과 할인율로 연결한다. 다른 기업의 주가 변화율 자체를 공급업체 매출 충격으로 전파하지 않는다.
- 금리는 회사별 할인율 반영과 수요·자금조달 경로를 구분한다. 기준금리 1%p 변화를 모든 회사의 할인율 1%p로 동일 적용하지 않는다.
- CAPEX 변화는 공급업체 주문, 투자기업 자신의 즉시 현금지출과 12개월 뒤 서비스 매출로 연결되는 가정 경로를 함께 바꾼다. 투자 확대를 자동으로 기업가치 상승으로 고정하지 않는다.
- HBM 가격은 판매단가·원가 경로, 공급량은 물량 경로로 분리한다. 물량 효과는 가정한 전이계수로 계산하며, 실제 수요 한도·생산 병목·재고 완충을 검증한 결과는 아니다. 기존 가동설비와 신규 공급의 차이는 추가 보정이 필요하다.
- 임대료 변화는 공급자 판매단가와 구매자 원가의 별도 경로에 반영한다. 데이터센터 임대료가 클라우드 비용을 거쳐 모델기업으로 전달되며 같은 비용을 다시 직접 부과하지 않는다. 고정 계약·갱신·신규 계약별 실측 반영 비율은 아직 없고 평균 전이계수를 가정한다.
- 모델매출 성장률은 매출 변화율과 다르다. 전년 매출이 100일 때 기준 성장률 100%는 매출 200, 변경 성장률 50%는 150으로 기준 대비 매출은 25% 감소한다. 기본 전파는 가격·효율이 동일한 사용량 변화 가정이며 가격 인상만으로 매출이 증가한 경우와 구별한다.
- FCFF에서 차입금 이자를 다시 차감하지 않는다. 순부채는 동일 평가시점의 기업가치에서 지분가치로 넘어갈 때만 반영한다.
- 임시 충격을 영구성장률 하락으로 자동 영속화하지 않는다. 충격 기간 이후 정상화와 발주·설치 시차를 모델 가정에 명시한다.
- 입력 0이면 기준 지수 100과 변화율 0이 유지돼야 한다. 범위를 벗어나거나 유한하지 않은 입력은 오류로 표시한다.

## 파일과 검증

- `assets/scenario-data.js`: 9개 SEG, 대표기업, 5개 시나리오 입력 정의와 명시적 가정.
- `assets/scenario-core.js`: 입력 검증, 전파·현금흐름·가치 계산.
- `assets/scenario.js`, `assets/scenario.css`: 선택·입력·결과·가정 편집 화면.
- `index.html`: 기존 사이트의 메뉴와 `#scenario` 경로.
- `tests/data/scenario*.test.mjs`: 모델 불변식과 사이트 연결 검증. `npm test`와 `npm run build`에 통합한다.

개인별 입력 저장은 브라우저 로컬 상태이며 공유 투자전략·게시글 발행이 아니다. 새로운 수집 API, 외부 AI 호출 또는 기존 커뮤니티 워커 활성화는 필요하지 않다.
