# 시장 현황 홈

첫 화면과 #today는 시장 현황이다. 기존 상세 AI 의견은 #opinions에서 원문·출처·이력과 함께 유지한다. #map, #compare, #data, #industry, #ai-stats, #talk 주소와 기능은 기존 화면으로 이어진다.

- 상단: 코스피·코스닥·S&P 500·나스닥·달러/원. 지수는 pt, 환율은 KRW / 1 USD로 표시한다.
- 본문: 동일 크기 종목 등락 타일, 고리별 평균·유효 n/N과 순위, 상승·하락 종목.
- 하단: 기존 실제 AI 발행 의견 요약, 수집한 DART 공시, 통계·토론 연결.
- 고리 선택은 #today?stage=3처럼 주소에 보존한다. 보조 편입을 포함하며 전체 타일에서는 종목을 중복 표시하지 않는다.
- 종목 타일 선택 후 거래가·관측/수집 시각을 확인하고 기존 차트·토론 화면으로 이동한다.

## 수치의 의미와 이번 범위

수치는 기존 공용 시세 스냅샷의 현재/최근 가격과 전일 종가 대비 변화율이다. 국가별 관측 거래일이 다르고 장중 값이 포함될 수 있다. 완료된 공통 거래일 수익률이나 공인 지수로 표현하지 않는다. 1개월~3년의 기존 동일 비중 흐름 비교는 #compare에 그대로 있다.

고리 평균은 정상 가격·등락률·관측/수집 시각을 가진 종목의 동일 비중 평균이다. 0%는 보합이며 결측으로 바꾸지 않는다. 미제공·오류·미래 관측·실패/이전값 상태의 종목은 등락 색·평균·상승/하락 순위에서 제외한다. 유효 종목 3개 미만 고리는 표본 부족으로 표시한다. 주·보조 고리 편입은 그룹 계산에 모두 포함하고 전체 종목 수와 상승·하락 수에서는 종목 코드를 중복 제거한다.

시가총액·통일된 FX·재무 지표가 연결되어 있지 않아 시총 면적 히트맵과 재무 필터는 구현하지 않았다. 동일 면적 타일임을 화면에 표시한다. 거래량 변화, 새 뉴스 공급원, 공급망 관계, 시장 개장/휴장 추론도 이번 범위에 포함하지 않는다.

홈은 기존 market-snapshot 이벤트와 공용 조회를 재사용한다. 타일·고리 선택은 새 원천 수집이나 모델 생성을 만들지 않는다. 홈에서 숨겨진 개별 종목 차트를 주기적으로 조회하지 않는다. 실제 모델 워커와 DB는 변경하지 않는다.

## 확인

시장 현황 모델 테스트는 동적 카탈로그, 중복·보조 편입, 누락/0/오류/미래 값, 실제 marketTime 초 단위 형식, 순위 최소 표본을 검증한다. 브라우저 smoke는 첫 화면, 고리 URL 재접속, 종목 선택·기존 차트 연결, 시세 실패 후 이전 값 유지와 복구, 1440/360/390/430px 화면을 확인한다. 기존 전체 AI 의견 검사는 #opinions에서 계속 수행한다.
