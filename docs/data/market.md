# 시세·기업·고리별 주가 비교

AI 체인의 시세·차트·관심종목과 고리별 비교는 같은 카탈로그와 시세 서비스를 사용한다. 현재 개발본은 이 저장소의 `index.html`, `assets/`, `server/market.mjs`다.

홈의 업종 가중방식·파급 계산은 [홈 파급과 가중 카드](home-ripple.md)를 따른다.

`npm run collect`는 원장을 읽어 위 대상을 수집하고 `data/market.json`을 검증·원자적으로 교체한다. 기본 최대 크기는 25 MB이며, 비밀 쿠키·인증 토큰은 저장하지 않는다. 라이브러리 인증 오류가 나면 같은 실행의 남은 일괄 조회를 중단하고 다음 수집에서 재시도한다. 기존 장중 스냅샷 가격을 종가라고 다시 표시하지 않는다. `coverage`의 원장 수·연결 후보 수·실제 종가 성공 수·시총 성공 수를 구분한다. 12개 본주 미연결과 제공처 미지원·상장폐지 등 실제 조회 실패는 별개다.

GitHub Actions는 UTC **08:20·10:20·18:20·23:20**, 한국 시간 **17:20·19:20·다음 날 03:20·08:20**에 실행한다. 각 시장 마감 이후 재확인하는 일정이며 원천 응답과 실행 지연이 있을 수 있다. 브라우저는 60초마다 새 파일만 확인한다. 30분마다 전체 시장을 다시 수집하지 않는다. 일별 스냅샷의 수집 지연은 96시간, 유효 종가의 장기 지연은 별도로 표시한다.

전체 JSON은 이력을 포함해 Vercel 함수 응답 한도보다 커질 수 있으므로 `/api/snapshot`은 기존 GitHub Pages의 고정 공개 JSON으로 307 이동시킨다. API 키·요청 헤더를 전달하지 않는다. 브라우저는 이동한 응답의 스키마를 확인하며 실패 시 기존 로컬 정적 파일을 읽고 저장본 표시를 유지한다.

홈 히트맵·버블은 사용자가 지정한 기능정의서의 **핵심기업 49** 시트와 같은 49개사(상장 46개·비상장 3개)를 대상으로 한다. 업종 카드·파급·과거 시총 보강은 같은 승인 목록의 상장 46개를 사용한다. 전체 회사 원장 586개와 위 555종목 수집은 별도로 유지한다. 신규 티커의 회사 동일성 검증 상태는 시세 조회 성공 여부와 구분한다.

## 홈 시장 지도: 승인 핵심기업 49 연결

선택 근거 `research/market/home-map-selection.json`은 원본 시트의 49개 이름·순서·주 섹터·승인 티커·상장 구분·역할을 보존한다. `assets/home-map-universe.js`는 이 선택을 회사 원장과 연결해 49개 고유 회사 ID, 상장 46개·비상장 3개(OpenAI·Anthropic·DeepSeek)의 안전한 식별 필드만 생성한다. 재생성 명령은 `node scripts/data/build-home-map-universe.mjs`다. 원본 시트는 수정하지 않으며 Excel·비공개 분석은 공개 모듈에 포함하지 않는다.

`assets/home-map-data.js`는 승인 49개 목록을 시장 스냅샷에 연결하고 합성 시총·등락률을 사용하지 않는다. `ASML.AS`·`2330.TW`·`0981.HK`·`GDS`·`BABA` 등 지정 티커를 그대로 사용하고 누락 시 다른 상장 종목으로 대체하지 않는다. 회사 ID당 하나의 면적만 만들며 비상장·제공처 결측도 대상과 사유에 남긴다. 한미반도체→반도체 소부장, 이수페타시스→AI 장비, 삼성전자→메모리, 알파벳→AI 모델처럼 시트의 주 섹터를 계산에도 적용한다.

업종 카드·파급·날짜별 시총 보강은 `assets/home-focus.js`에서 승인 상장 목록을 직접 파생한다. 섹터당 5개를 가정하지 않으며 AI 모델의 수익률 대상은 상장 2개(알파벳·메타)다. 비상장 3개에 가격·수익률·임의 시총을 만들지 않는다.

타일·원의 면적은 최근 제공처 관측 시총의 USD 환산값이다. `marketCapObservedAt`, 원 시총 통화와 환율 적용일을 보존하며 과거 기간 시작 시총이나 종가 시총으로 가장하지 않는다.

색상과 버블 세로 위치는 선택한 **1일·1주·1개월·1년의 완료 종가 수익률**이다. 시총·통화·환율·확정 종가가 없으면 해당 기업은 면적 지도에서 제외하고 사유와 반영 수를 표시한다. 선택 기간 수익률만 없으면 히트맵은 중립색·`—`, 버블은 제외한다. 결측을 0%나 임의 시총으로 채우지 않는다. 이전값은 원래 기준일·관측 시각과 상태를 유지한다.

FX 이력은 KRW·JPY·TWD·EUR·CHF·HKD·SGD·CNY·AED·AUD·BRL·CAD·IDR·INR·MYR·NZD·QAR·SAR·SEK·THB·TRY·DKK·GBP 23개 통화의 **현지 통화 단위/USD 1달러**로 수집한다. 최초 검증본에서 실제 시총의 확인된 통화는 USD와 비달러 21개였다. DKK·GBP 환율이 있어도 시총 통화가 미확인인 종목은 계속 제외한다. 원 시총을 이 환율로 나누어 USD로 환산한다. 지도는 시총 관측 시점보다 늦지 않은 최신 확정 환율만 사용하며 최대 7일 이내라는 제한과 적용 환율 날짜를 보존한다. 업종 카드의 가중 계산은 별도로 정확한 기간 시작일 시총·동일 날짜 환율을 요구한다. 자세한 기준은 [홈 파급과 가중 카드](home-ripple.md)를 따른다.

- 기업 역할·국가·공식 출처는 `assets/company-profiles.js`, 시세·차트·관심종목 화면은 `assets/dashboard.js`, 비교 계산은 `assets/peer-comparison-core.js`가 담당한다. 비교 화면은 dashboard의 `market-snapshot` 이벤트를 공유한다.

## 출처·조회·저장 범위

출처는 Yahoo Finance의 비공식 공개 chart 조회 경로다. 실제 거래소 실시간 데이터가 아니며 지연·호출 제한·제공처 변경이 발생할 수 있다. 실패를 임의 가격으로 채우지 않는다. 휴장 중 장중 차트가 없으면 실제 가격과 기준시각만 표시한다. TSM은 미국 상장 ADR(USD)이다.

- 로컬 및 Vercel에서는 같은 코드의 /api/chart가 임의 티커와 선택한 종목의 최신 시세를 조회한다. 서버 캐시 60초, 요청 중복 제거, 제한시간과 보조 호스트 재시도가 있다.

- Pages는 정적 호스팅이므로 수집된 93개 종목·모든 기간 차트·관심종목 기능을 제공한다. 카탈로그 밖 임의 티커 조회는 로컬/API 배포에서 제공하며 화면에 이 차이를 안내한다.

- 데이터의 기준시각·개별 수집시각·전체 수집시각을 구분한다. 개별 실패 시 이전 값과 원래 시각을 유지한다. 오래된 수집·조회 실패를 표시한다.

- 관심종목·추가 종목은 동일 브라우저·동일 사이트 주소에 저장한다. stock-site의 기존 watch 키는 같은 주소에서 가능한 경우 읽어온다. 서로 다른 localhost 포트·도메인의 저장값은 자동으로 공유되지 않는다.

공개 스냅샷과 호스팅별 제공 방식은 [배포 안내](../deployment/overview.md)를 따른다. API 키·토큰·환경 파일은 브라우저 코드와 공개 데이터에 넣지 않는다.

## 수집 명령

저장소 루트에서 `npm run collect`를 실행하면 원장의 연결 후보와 기존 종목·지표의 확정 종가, 시총과 차트 스냅샷을 수집한다. 브라우저의 다시 조회는 원천 수집 명령과 별개이며 배포된 최신 파일을 읽는다.

## 8개 고리 피어 주가 비교

상단 고리 비교 메뉴(#compare)에서 소부장·파운드리·메모리·AI 칩·전력·인프라·모델·애플리케이션 8개를 한 차트로 비교한다. 1개월(30일)·3개월(90일)·6개월(180일)·1년(365일)·2년(730일)·3년(1,095일) 중 선택하며, 실제 공통 기준일·종료일을 표시한다.

각 종목의 현지 통화 종가를 공통 기준일100으로 정규화한 뒤 고리별 동일 비중으로 평균한다. 평균 주가 금액이나 시가총액 가중·일별 리밸런싱·배당 포함·환율 환산 성과가 아니다. 현재 75개 고유 피어를 77개 고리 소속으로 사용하며 삼성전자(파운드리·메모리)와 NAVER(모델·애플리케이션)는 각각 두 고리에 포함된다. 혼합사업·범용 메모리 업체의 사업 범위는 기업 목록에 표시한다. 등록 피어는 과거 기간에도 같은 목록을 적용한다.

각국 거래소의 현지 날짜를 교차 정렬하며 모든 유효 피어에 종가가 있는 날만 비교한다. 미래 관측·유효하지 않은 종가를 제외하고 결측일 보간이나 일별 분모 변경은 하지 않는다. 제외 피어·실제 기간 단축·오래된 수집값은 표시한다. 새 수집본은 종료·유예시간을 확인한 일봉만 사용한다. 저장된 이전 수집본의 기준일과 실패 상태는 보존한다.

8개 선은 범례로 숨기거나 다시 표시할 수 있다. 날짜 슬라이더/마우스로 동일 날짜 수치를 조회하고, 아래 카드에서 피어별 등락률·기준 종가·마지막 종가·출처를 확인한다. 1년 이내 비교는 기존 시세 스냅샷을 공유한다.


### 회사별 비교와 3년 일봉

기본 화면은 기존 **고리 평균**이다. **회사별 비교**에서는 차트 위의 고리별 회사 선택 목록에서 체크박스로 서로 다른 고리의 회사도 함께 고른다. 여러 고리에 속한 같은 회사는 선택 상태를 공유하며 한 번만 계산한다. 고리별 바로가기로 목록 안에서 이동하며, 선택해도 목록의 스크롤 위치를 유지한다. 선택 목록을 접어 차트를 볼 수 있고, 선택한 회사는 해제하거나 전체 비우기를 할 수 있다. 기간을 바꾸거나 최신 수집값을 읽어도 선택을 유지한다. 선택한 회사의 현지 통화 종가를 공통 기준일 100으로 정규화하며 회사끼리 평균하지 않는다. 날짜 조회·범례는 현재 비교 모드와 실제 공통 기간을 따른다. 미선택 회사의 짧은 이력은 회사별 비교 기간에 영향을 주지 않는다.

`npm run collect:comparison`은 AI 기업 75개의 최근 3년과 휴장 정렬용 14일 여유분을 일별 종가만으로 `data/comparison-history.json`에 수집한다. 서버의 논리 범위 `3y`는 실제 시작·종료 시각과 일봉 간격으로 요청하며 5년 주봉이나 1년 일봉으로 대체하지 않는다. 이 파일은 2년·3년 선택 시에만 별도로 읽는다. 로컬·Vercel은 `/api/comparison-history`, Pages는 정적 파일을 사용한다. 화면 조회는 수집을 실행하지 않는다.

긴 기간의 고리 평균은 요청한 기간의 시작·종료 부근까지 관측이 있는 고정 피어만 사용한다. 이력이 부족한 피어와 실제 최초·최종 관측일을 목록에 표시한다. 회사별 비교에서 신규 상장 등으로 기간이 짧아지면 실제 공통 기간과 단축 경고를 표시한다. 같은 날짜의 유효 종가만 사용하며 보간·환율 환산·배당 재투자를 하지 않는다.

개별 수집 실패는 이전 종가와 원래 `fetchedAt`을 보존하고 오래됨·실패 상태를 남긴다. 전체 실패 또는 4,000,000바이트 제한 초과 시 이전 파일을 유지한다. 성공 파일은 검증 후 원자적으로 교체한다. 새 공개 파일도 빌드의 명시적 허용목록과 검증을 거친다. 하루 4회 Pages 수집 작업에 포함하며 별도 폴링·AI 호출·유료 API를 추가하지 않는다.
