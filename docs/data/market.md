# 시세·기업·고리별 주가 비교

AI 체인의 시세·차트·관심종목과 고리별 비교는 같은 카탈로그와 시세 서비스를 사용한다. 현재 개발본은 이 저장소의 `index.html`, `assets/`, `server/market.mjs`다.

홈의 업종 가중방식·파급 계산은 [홈 파급과 가중 카드](home-ripple.md)를 따른다.

## 현재 운영: 시세 수집 중지 (2026-11-07)

사용자 요청에 따라 **GitHub 코드 보관과 GitHub Pages 배포만** 진행한다. Vercel 추가 배포·유료 전환은 하지 않는다. 새 종가·시총·환율·주가 비교 이력 수집, 실시간 차트 API 호출과 브라우저 자동 폴링을 중지했다. 사용자가 명시적으로 재개하기 전까지 이 정책을 유지한다.

`assets/market-data-policy.js`의 정책에 따라 브라우저는 처음에 `data/market-display.json`을 안정된 URL과 `force-cache`로 한 번만 읽는다. 이 표시본은 기존 555개 종목·지표의 메타데이터와 얇은 종가·시각 시계열을 보존한다. 원래 종가 기준일·시총 관측 시각·수집 실패 상태를 유지하며 최신 조회값으로 표시하지 않는다. ‘저장값 확인’은 화면을 다시 계산하고 원격 파일을 재다운로드하지 않는다. 저장 자료가 없는 종목·기간은 결측으로 남긴다.

전체 보관 파일 `data/market.json`은 변경하지 않는다. 경량 표시본에 없는 과거 시가·고가·저가·거래량을 복원하거나 만들지 않으며, 경량 화면이 전체 OHLCV 이력을 제공한다고 안내하지 않는다.

Pages 작업의 시간 예약은 제거하고 `main` 변경·수동 배포만 남긴다. 배포 시 보관 시세를 사용하며 새 시세·3년 주가 이력을 수집하지 않는다. 기타 자료 작업은 기존 push·수동 배포 절차를 유지한다.

## 보관된 종가의 수집 기준

기존 보관 스냅샷은 `mode: scheduled-close`, `priceBasis: previous-completed-session`으로 수집했다. 아래는 보관 자료의 계산·출처 기준이며 수집 재개 지시가 아니다. 목록·비교 계산은 저장된 종가를 사용한다.

| 종목 연결 후보 | 상장 525개사의 대표 티커. 본주 미연결 PLDT의 PHI ADR을 별도로 포함해 고유 555종목: 기존 93종목 보존, 462종목 추가 |

수집 중지 전 `npm run collect`는 원장을 읽어 위 대상을 수집하고 `data/market.json`을 검증·원자적으로 교체했다. 현재 운영 절차에서는 실행하지 않는다. 기본 최대 크기는 25 MB이며, 비밀 쿠키·인증 토큰은 저장하지 않는다. 라이브러리 인증 오류가 나면 같은 실행의 남은 일괄 조회를 중단하고 다음 수집에서 재시도한다. 기존 장중 스냅샷 가격을 종가라고 다시 표시하지 않는다. `coverage`의 원장 수·연결 후보 수·실제 종가 성공 수·시총 성공 수를 구분한다. 12개 본주 미연결과 제공처 미지원·상장폐지 등 실제 조회 실패는 별개다.

종가 자료의 장기 지연과 이전 수집 상태는 화면에 표시한다. 현재는 예약 수집과 60초 새로고침을 사용하지 않는다. `/api/snapshot`·`/api/chart`의 기존 구현은 보존하지만 현재 브라우저에서는 호출하지 않으며, 경량 표시본 조회 실패 시 전체 22MB 파일이나 실시간 API로 우회하지 않는다.

홈 히트맵·버블은 기능정의서의 원본 **핵심기업 49** 시트에 2026-11-08 사용자 요청으로 Qualcomm(QCOM, C0371)을 AI 칩 핵심에 추가한 50개사(상장 47개·비상장 3개)를 대상으로 한다. 업종 카드·파급·과거 시총 계산은 같은 승인 목록의 상장 47개를 대상으로 하며 AI 칩은 6개다. 전체 회사 원장 586개와 기존 555종목 보관 파일은 유지한다. QCOM은 기존 회사의 핵심 편입이며 새 회사 생성이나 원천 시세 추가 수집을 뜻하지 않는다. 신규 티커의 회사 동일성 검증 상태는 시세 조회 성공 여부와 구분한다.

## 홈 시장 지도: 승인 핵심기업 50 연결

선택 근거 `research/market/home-map-selection.json`은 원본 시트의 49개 이름·순서·주 섹터·승인 티커·상장 구분·역할을 수정 없이 보존한다. 별도 `research/market/home-map-additions.json`은 `user-request`·`2026-11-08`의 QCOM(C0371) 추가만 기록한다. 생성기는 원본 뒤 순서 50으로 이를 합성하며 `baseCompanyCount: 49`와 `userAdditions` 출처를 보존한다. `assets/home-map-universe.js`는 회사 원장과 연결한 50개 고유 회사 ID, 상장 47개·비상장 3개(OpenAI·Anthropic·DeepSeek)의 안전한 식별 필드만 생성한다. 재생성 명령은 `node scripts/data/build-home-map-universe.mjs`다. 원본 시트명과 SHA-256은 변경하지 않으며 Excel·비공개 분석은 공개 모듈에 포함하지 않는다.

`assets/home-map-data.js`는 승인 50개 목록을 시장 스냅샷에 연결하고 합성 시총·등락률을 사용하지 않는다. `ASML.AS`·`2330.TW`·`0981.HK`·`GDS`·`BABA` 등 지정 티커를 그대로 사용하고 누락 시 다른 상장 종목으로 대체하지 않는다. 회사 ID당 하나의 면적만 만들며 비상장·제공처 결측도 대상과 사유에 남긴다. 한미반도체→반도체 소부장, 이수페타시스→AI 장비, 삼성전자→메모리, 알파벳→AI 모델처럼 시트의 주 섹터를 계산에도 적용한다.

업종 카드·파급·날짜별 시총 계산 대상은 `assets/home-focus.js`에서 사용자 추가를 합성한 승인 상장 목록을 직접 파생한다. QCOM의 필요한 관측값이 없으면 결측으로 남기며 새로 수집하거나 임의 이력을 만들지 않는다. 섹터당 5개를 가정하지 않으며 AI 모델의 수익률 대상은 상장 2개(알파벳·메타)다. 비상장 3개에 가격·수익률·임의 시총을 만들지 않는다.

타일·원의 면적은 최근 제공처 관측 시총의 USD 환산값이다. `marketCapObservedAt`, 원 시총 통화와 환율 적용일을 보존하며 과거 기간 시작 시총이나 종가 시총으로 가장하지 않는다.

색상과 버블 세로 위치는 선택한 **1일·1주·1개월·1년의 완료 종가 수익률**이다. 시총·통화·환율·확정 종가가 없으면 해당 기업은 면적 지도에서 제외하고 사유와 반영 수를 표시한다. 선택 기간 수익률만 없으면 히트맵은 중립색·`—`, 버블은 제외한다. 결측을 0%나 임의 시총으로 채우지 않는다. 이전값은 원래 기준일·관측 시각과 상태를 유지한다.

보관된 FX 이력은 KRW·JPY·TWD·EUR·CHF·HKD·SGD·CNY·AED·AUD·BRL·CAD·IDR·INR·MYR·NZD·QAR·SAR·SEK·THB·TRY·DKK·GBP 23개 통화의 **현지 통화 단위/USD 1달러** 기준이다. 최초 검증본에서 실제 시총의 확인된 통화는 USD와 비달러 21개였다. DKK·GBP 환율이 있어도 시총 통화가 미확인인 종목은 계속 제외한다. 원 시총을 이 환율로 나누어 USD로 환산한다. 지도는 시총 관측 시점보다 늦지 않은 최신 확정 환율만 사용하며 최대 7일 이내라는 제한과 적용 환율 날짜를 보존한다. 업종 카드의 가중 계산은 별도로 정확한 기간 시작일 시총·동일 날짜 환율을 요구한다. 자세한 기준은 [홈 파급과 가중 카드](home-ripple.md)를 따른다.

- AI 기업 75개(국내 18개·해외 57개)와 시장·기타 지표를 합쳐 93개(고유 티커), 인프라에는 EQIX·DLR·Keppel DC REIT·Iron Mountain 포함

- 저장된 종가·시각이 있는 기간의 차트와 CSV. 경량 표시본에 없는 OHLCV 값은 미제공으로 표시

- 기업정보(`#data`)는 AI 기업 75개의 사업·국가·공식 자료와 실제 시세를 함께 제공한다. 8개 고리, 국내·해외, 기업명·티커·사업 검색을 지원한다. 목록과 비교는 같은 `assets/instruments.js` 카탈로그를 쓴다.
- 기업 역할·국가·공식 출처는 `assets/company-profiles.js`, 시세·차트·관심종목 화면은 `assets/dashboard.js`, 비교 계산은 `assets/peer-comparison-core.js`가 담당한다. 비교 화면은 dashboard의 `market-snapshot` 이벤트를 공유한다.
- 기업 카드의 공시와 토론 연결은 [DART 공시](company-disclosures.md), [커뮤니티 현황](../community/ai-community.md)을 따른다.

## 출처·조회·저장 범위

출처는 Yahoo Finance의 비공식 공개 chart 조회 경로다. 실제 거래소 실시간 데이터가 아니며 지연·호출 제한·제공처 변경이 발생할 수 있다. 실패를 임의 가격으로 채우지 않는다. 휴장 중 장중 차트가 없으면 실제 가격과 기준시각만 표시한다. TSM은 미국 상장 ADR(USD)이다.

- 기존 `/api/chart` 코드는 보존하지만 현재 로컬·Pages 브라우저에서 실시간 조회하지 않는다. 새 티커와 차트의 원천 조회는 사용자의 명시적 재개 이후에만 사용한다.

- Pages는 경량 저장본의 종가·기간 자료와 관심종목 기능을 제공한다. 모든 기간·모든 OHLCV가 있다고 가정하지 않으며 저장되지 않은 자료는 추가 조회하지 않는다.

- 데이터의 기준시각·개별 수집시각·전체 수집시각을 구분한다. 개별 실패 시 이전 값과 원래 시각을 유지한다. 오래된 수집·조회 실패를 표시한다.

- 관심종목·추가 종목은 동일 브라우저·동일 사이트 주소에 저장한다. stock-site의 기존 watch 키는 같은 주소에서 가능한 경우 읽어온다. 서로 다른 localhost 포트·도메인의 저장값은 자동으로 공유되지 않는다.

공개 스냅샷과 호스팅별 제공 방식은 [배포 안내](../deployment/overview.md)를 따른다. API 키·토큰·환경 파일은 브라우저 코드와 공개 데이터에 넣지 않는다.

## 중지와 재개

현재 운영 절차에서는 `npm run collect`와 `npm run collect:comparison`을 실행하지 않는다. 수집기 구현·원장·기존 보관 파일을 보존하며, 사용자가 시세 수집 재개를 명시적으로 요청한 뒤 정책과 배포 절차를 함께 검토한다. 브라우저의 ‘저장값 확인’은 원천 조회나 파일 재다운로드를 시작하지 않는다.

## 8개 고리 피어 주가 비교

상단 고리 비교 메뉴(#compare)에서 소부장·파운드리·메모리·AI 칩·전력·인프라·모델·애플리케이션 8개를 한 차트로 비교한다. 1개월(30일)·3개월(90일)·6개월(180일)·1년(365일)·2년(730일)·3년(1,095일) 중 선택하며, 실제 공통 기준일·종료일을 표시한다.

각 종목의 현지 통화 종가를 공통 기준일100으로 정규화한 뒤 고리별 동일 비중으로 평균한다. 평균 주가 금액이나 시가총액 가중·일별 리밸런싱·배당 포함·환율 환산 성과가 아니다. 현재 75개 고유 피어를 77개 고리 소속으로 사용하며 삼성전자(파운드리·메모리)와 NAVER(모델·애플리케이션)는 각각 두 고리에 포함된다. 혼합사업·범용 메모리 업체의 사업 범위는 기업 목록에 표시한다. 등록 피어는 과거 기간에도 같은 목록을 적용한다.

각국 거래소의 현지 날짜를 교차 정렬하며 모든 유효 피어에 종가가 있는 날만 비교한다. 미래 관측·유효하지 않은 종가를 제외하고 결측일 보간이나 일별 분모 변경은 하지 않는다. 제외 피어·실제 기간 단축·오래된 수집값은 표시한다. 새 수집본은 종료·유예시간을 확인한 일봉만 사용한다. 저장된 이전 수집본의 기준일과 실패 상태는 보존한다.

8개 선은 범례로 숨기거나 다시 표시할 수 있다. 날짜 슬라이더/마우스로 동일 날짜 수치를 조회하고, 아래 카드에서 피어별 등락률·기준 종가·마지막 종가·출처를 확인한다. 1년 이내 비교는 기존 시세 스냅샷을 공유한다.


### 회사별 비교와 3년 일봉

기본 화면은 기존 **고리 평균**이다. **회사별 비교**에서는 차트 위의 고리별 회사 선택 목록에서 체크박스로 서로 다른 고리의 회사도 함께 고른다. 여러 고리에 속한 같은 회사는 선택 상태를 공유하며 한 번만 계산한다. 고리별 바로가기로 목록 안에서 이동하며, 선택해도 목록의 스크롤 위치를 유지한다. 선택 목록을 접어 차트를 볼 수 있고, 선택한 회사는 해제하거나 전체 비우기를 할 수 있다. 기간을 바꾸거나 최신 수집값을 읽어도 선택을 유지한다. 선택한 회사의 현지 통화 종가를 공통 기준일 100으로 정규화하며 회사끼리 평균하지 않는다. 날짜 조회·범례는 현재 비교 모드와 실제 공통 기간을 따른다. 미선택 회사의 짧은 이력은 회사별 비교 기간에 영향을 주지 않는다.

수집 중지 전 `npm run collect:comparison`은 AI 기업 75개의 최근 3년과 휴장 정렬용 14일 여유분을 일별 종가만으로 `data/comparison-history.json`에 보관했다. 서버의 논리 범위 `3y`는 실제 시작·종료 시각과 일봉 간격으로 요청하며 5년 주봉이나 1년 일봉으로 대체하지 않는다. 이 파일은 2년·3년 선택 시에만 별도로 읽는다. 현재 비교는 보관 파일만 사용하며, 새 주가 수집을 실행하지 않는다.

긴 기간의 고리 평균은 요청한 기간의 시작·종료 부근까지 관측이 있는 고정 피어만 사용한다. 이력이 부족한 피어와 실제 최초·최종 관측일을 목록에 표시한다. 회사별 비교에서 신규 상장 등으로 기간이 짧아지면 실제 공통 기간과 단축 경고를 표시한다. 같은 날짜의 유효 종가만 사용하며 보간·환율 환산·배당 재투자를 하지 않는다.

개별 수집 실패는 이전 종가와 원래 `fetchedAt`을 보존하고 오래됨·실패 상태를 남긴다. 전체 실패 또는 4,000,000바이트 제한 초과 시 이전 파일을 유지한다. 성공 파일은 검증 후 원자적으로 교체한다. 새 공개 파일도 빌드의 명시적 허용목록과 검증을 거친다. 현재 예약 수집은 중지되어 있으며 별도 폴링·AI 호출·유료 API를 추가하지 않는다.
