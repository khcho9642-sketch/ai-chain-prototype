# AI 체인 프로토타입

AI Value Chain 8단계 주주 플랫폼(가칭 AI 체인) 화면 프로토타입입니다. 신호 판정과 [값]은 예시이며 실제 데이터가 아닙니다. 매수·매도를 추천하지 않습니다.

`index.html`을 브라우저로 열면 바로 볼 수 있어요.

## 실제 주가 연결 (2026-10-26)

8개 고리의 대표 종목 21개와 시장지표 5개의 실제 시세를 연결했습니다. 기존 산업지표·AI·신호 예시는 그대로 구분합니다. 시세가 산업지표 판정을 대체하지 않습니다.

- 출처: Yahoo Finance 공개 비공식 chart 조회 경로. 공식 가용성/실시간성이 보장되지 않으며 지연·호출 제한이 있습니다.
- 가격, 전일 대비, 거래량, 고가·저가, 52주 범위, 최근 1년 일봉 OHLCV와 CSV. TSM은 미국 상장 ADR(USD)이며 대만 본주 가격과 다릅니다.
- 각 종목의 시세 기준시각, 수집시각, 통화, 거래소와 출처 링크를 표시합니다. null은 미제공이며 임의 숫자로 채우지 않습니다.
- GitHub Actions `.github/workflows/market-pages.yml`이 30분 간격으로 수집 후 GitHub Pages에 배포합니다. 예약 실행은 GitHub 사정에 따라 지연되거나 비활성화될 수 있으며 실시간 스트리밍이 아닙니다.
- 브라우저는 60초마다 최신 **배포된 스냅샷**을 다시 읽습니다. 다시 읽기 버튼은 제공처 수집을 직접 실행하지 않습니다. 즉시 새 수집은 Actions의 Run workflow를 사용하세요.
- 개별 실패는 이전 시세와 기존 기준시각을 보존하고 실패 표시합니다. 수집시각이 90분 이상 지났으면 지연 표시합니다. 전체 수집 실패도 이전 파일을 유지하여 실패 상태와 함께 배포합니다.
- 배포 시 JSON은 워크플로 아티팩트에 포함됩니다. 예약 수집마다 main에 커밋하지 않으므로 저장소의 JSON은 초기 스냅샷입니다.
- `design/`은 배포 아티팩트에서 제외합니다. API 키는 사용하지 않습니다. DART·관세청·TSMC 산업지표 자동 수집은 별도 후속 작업입니다.

로컬 확인: Node.js 20+에서 `node scripts/collect-market.mjs`, `node scripts/serve.mjs` 후 http://127.0.0.1:5175 접속. file:// 직접 열기는 JSON 요청이 차단될 수 있으므로 로컬 서버를 사용하세요.
테스트: `node --test scripts/market.test.mjs`.

데이터센터 리츠는 인프라 고리에 포함: 에퀴닉스(EQIX), 디지털 리얼티(DLR). 리츠의 AFFO·임대율·임대계약·부채 만기·배당 지표는 현재 자동 수집하지 않으며 해당 기업 IR 자료 확인 후 별도 연결합니다.
