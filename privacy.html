GOOGLE 로그인

로그인 정보 처리 안내

안내 기준일: 2026년 11월 9일

이 안내는 AI Value Chain의 Google 로그인 기능이 처리하는 정보를 설명합니다.

로그인은 선택 사항입니다. 로그인하지 않아도 시장 지도와 기존 공개 자료를 읽을 수 있습니다. 처음 Google 로그인을 완료하면 이 사이트의 회원 계정이 만들어집니다.

어떤 정보를 사용하나요?

정보사용 목적
Google 계정 고유 식별자다시 로그인할 때 같은 회원을 찾는 데 사용합니다. 이메일이 같다는 이유만으로 다른 회원 계정을 연결하지 않습니다.
Google 이름·이메일회원 계정에 저장하고 본인의 ‘내 계정’ 화면에 표시합니다. Google로 다시 로그인하면 최신 값으로 갱신합니다.
사이트 회원 ID·계정 상태·가입 시각·최근 로그인 시각계정과 로그인 상태를 관리합니다. 최근 로그인 시각은 Google 인증을 완료한 시각이며, 사이트 방문이나 모든 활동을 기록한 시각은 아닙니다.
로그인 세션·보안 확인값·요청 제한 정보로그인 유지, 로그인 요청의 재사용 방지, 과도한 인증 요청 제한에 사용합니다.

Google 비밀번호는 이 사이트에 입력하거나 전달하지 않습니다. Gmail·Google Drive의 내용에 접근할 권한을 요청하지 않으며 프로필 사진은 회원 DB에 저장하지 않습니다.

요청 제한을 위해 접속 IP 주소로부터 만든 해시값과 요청 횟수·만료 시각을 저장합니다. 이 인증 DB에는 원문 IP 주소를 저장하지 않습니다.

정보는 어떻게 처리되나요?

Google 로그인 화면에서 계정을 선택하고 인증하면, Google이 전달한 신원 확인용 토큰을 이 사이트의 서버가 검증합니다. 검증한 계정 식별자로 회원을 찾거나 새로 만들고 이름과 이메일을 저장합니다.

인증 서버와 회원 저장소는 Cloudflare Pages Functions와 D1을 사용합니다. 로그인 토큰 원문을 회원 DB나 브라우저의 localStorage·sessionStorage에 저장하지 않습니다. DB에는 별도로 발급한 세션과 보안 확인값을 해시 형태로 저장합니다.

로그인 과정에서 브라우저는 Google 인증 서비스와, 사이트 요청은 Cloudflare 서비스와 통신합니다. 해당 서비스의 정보 처리는 Google 개인정보처리방침과 Cloudflare 개인정보처리방침도 참고할 수 있습니다.

로그인 쿠키

  • 로그인 유지 쿠키: 로그인한 브라우저의 세션을 확인하며 유효기간은 발급 후 최대 7일입니다. 쿠키 이름은 __Host-ai_chain_session입니다.
  • 로그인 확인 쿠키: 지금 시작한 로그인 요청을 확인하는 데 사용하며 유효기간은 최대 10분입니다. 쿠키 이름은 __Host-ai_chain_nonce입니다.

운영 사이트의 두 쿠키는 HTTPS 연결에서만 전송되고, 브라우저 JavaScript가 직접 읽을 수 없도록 설정합니다. 쿠키를 차단하거나 삭제하면 로그인 또는 로그인 유지가 작동하지 않을 수 있습니다.

보관과 로그아웃

회원 정보에는 자동 만료 기간이 설정되어 있지 않습니다. 로그아웃은 현재 브라우저의 세션을 종료하며 회원 정보 자체를 삭제하지 않습니다.

만료된 세션과 로그인 확인값은 더 이상 인증에 사용할 수 없습니다. 만료된 세션 DB 기록은 이후 로그인 처리 때, 만료된 확인값·요청 제한 기록은 이후 로그인 확인값 발급 때 정리합니다. 위의 7일·10분은 유효기간이며 DB 기록이 그 시각에 즉시 삭제된다는 의미는 아닙니다.
